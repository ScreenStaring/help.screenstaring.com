# Entry via Barcode Scanner

Improve the efficiency of inventory intake and inventory batch assignment by scanning a product's barcode instead of having to search for the product by typing its name, SKU, or barcode. To get started install [the Barcode Scanner app](https://apps.shopify.com/barcode-scanner-1?utm_source=product-expiration-dates&utm_medium=app&utm_campaign=barcode-scanner). The Barcode Scanner app must be used from within [the Shopify Mobile app](https://www.shopify.com/mobile).
