# Entry via Barcode Scanner

Improve the efficiency of inventory intake and inventory batch assignment by scanning a product's barcode instead of having to search for the product by typing its name, SKU, or barcode.
To get started install [the Barcode Scanner app](https://apps.shopify.com/barcode-scanner-1?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).
The Barcode Scanner app must be used from within [the Shopify Mobile app](https://www.shopify.com/mobile).
