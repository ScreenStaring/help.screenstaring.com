# Sharing Inventory Between Multiple Stores

If your inventory supplies multiple stores these stores can be linked. Linking stores allows a singe set of expiration data to be shared across multiple stores.

To link stores you must:

-   Install the app in each store (after the trial period all stores must have an active subscription)
-   Use the same product SKUs in each store (barcode can be used instead, if you prefer)
-   If using locations, use the same location names in each store
-   [Contact support](https://screenstaring.com/#contact) to create the link(s)
