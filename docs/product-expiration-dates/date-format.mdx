# Changing the Date and Time Format

The date format displayed in the app is determined by your locale. Your locale can be changed on the <Link path="/settings#general">settings page's general tab</Link>. By default we use the locale provided by Shopify. Changing the locale does not affect inventory batch expiration dates. It only changes the format used to display them.

The date format displayed on your site can be configured when [adding expiration data to your site](/docs/product-expiration-dates/shopify-pages).
