# Adding Expiration Data to Your Site

It is possible to access and/or display expiration data from your site. This includes expiration dates, their quantities, and use within data. The easiest way to display this information is to use our [Shopify theme editor](https://help.shopify.com/en/manual/onine-store/themes/customizing-themes/theme-editor/using-the-theme-editor#access-the-theme-editor) integration, which allows the expiration data to be added [as a section or block](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/using-the-theme-editor#sections-and-blocks).

1.  <ShopifyLink href={(shopify) => shopify.themes()}>Go to your Themes in the Shopify Admin</ShopifyLink>
2.  Find the theme you want to update and click "Edit theme"
3.  In the theme editor, select the template you'd like to add expiration data to:
    
    <img src="/product-expiration-dates/shopify/images/theme-editor-select-template.jpg" height="500" alt="Select theme template" />
    
4.  Select the desired location within the template. This can be done by hovering your cursor over the desired insertion area:
    
    <img src="/product-expiration-dates/shopify/images/theme-editor-add-block-button.jpg" height="500" alt="Add block button" />
    
5.  Click on the add block button and select Expiration Data from the Apps section:
    
    <img src="/product-expiration-dates/shopify/images/theme-editor-add-app-block.jpg" height="500" alt="Add Expiration Dates app block button" />
    
6.  This will add an Expiration Data block to the selected template:
    
    <img src="/product-expiration-dates/shopify/images/theme-editor-block-added.jpg" height="500" alt="Expiration Dates app block added" />
    
7.  Click on the Expiration Data block to access additional configuration options. For products with multiple variants, the selected variant's expiration data will be shown. Multiple blocks can be added to address diffrent use cases. For example, you can add 1 block to show expiration dates, and another to show use within data.
8.  Click <kbd>Save</kbd>

## Adding our Snippet to Your Theme {/* #adding-liquid-snippet */}

**Adding expiration data should be done via [our Shopify theme integration](/docs/product-expiration-dates/shopify-pages). Explicitly adding the snippet is only necessary for specialized cases.**

1.  <ShopifyLink href={(shopify) => shopify.toString()}>Go to the Shopify Admin</ShopifyLink>
2.  [Open your theme's code editor](https://shopify.dev/docs/storefronts/themes/tools/code-editor#accessing-the-code-editor)
3.  [Add a new theme file](https://shopify.dev/docs/storefronts/themes/tools/code-editor#adding-theme-files)
    -   Click on the "snippets" directory
    -   Click "Add new snippet"
    -   For file name use `ss-product-expiration-dates`
    -   Click "Done"
4.  This will open a new blank tab in the editor named `snippets/ss-product-expiration-dates.liquid`
5.  Copy the code from [our Liquid snippet](/product-expiration-dates/images/ss-product-expiration-dates.txt) and paste it into the tab
6.  Click <kbd>Save</kbd>

## Displaying the Expiration Data

Once you've [added our snippet to your theme](/docs/product-expiration-dates/shopify-pages#adding-liquid-snippet) the next step is to render it in the location you want the expiration data displayed. This can be done from the Shopify Admin via the customize theme page.

1.  <ShopifyLink href={(shopify) => shopify.themes()}>Go to your Themes in the Shopify Admin</ShopifyLink>
2.  Find the theme you want to update and click "Edit theme"
3.  In the theme editor, select "Products" then "Default product" (or whatever the desired template is)
4.  In the Template section click "Add block"
5.  Select "Custom liquid" or, if not available, "HTML" (note that the "HTML" block must support Liquid)

-   If your theme does not have a "Custom liquid" nor "HTML" option you must render the snippet in your theme manually
-   This can be done via [the theme code editor](https://shopify.dev/docs/themes/tools/code-editor)
-   If you need assistance please [contact support](https://screenstaring.com/#contact)

7.  Once selected you can move the Custom Liquid block to location you want the expiration data displayed
8.  Click on the Custom Liquid block you just added
9.  In the "Custom liquid" (or similar) field paste the desired render code, see Expiration Data Display Options for examples
10.  Click <kbd>Save</kbd>

## Display the Expiration Dates Based on User Language/Region {/* #display-language-region */}

If you are displaying your site in multiple languages you can change the expiration date format and text based on the currently selected language and/or region. Instead of rendering the expiration date via the default code:

```liquid
{% render "ss-product-expiration-dates", product: product, prefix: "Best by:", format: "%B %d, %Y" %}
```

You can use the following code to check the selected language and/or region and display the expiration date and text in a specific format:

```liquid
{% assign locale = request.locale.iso_code %}
{% assign lang = locale | split: "-" | first %}
{% if lang == "es" %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Consúmase antes de:", format: "%d/%m/%Y" %}
{% elsif lang == "de" %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Mindestens haltbar bis:", format: "%d.%m.%Y" %}
{% else %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Best by:", format: "%B %d, %Y" %}
{% endif %}
```

Here if the language is Spanish (`"es"`) the text `"Consúmase antes de:"` is shown and the date is displayed in `DD/MM/YYYY` format. If the language is German (`"de"`) the text and date are displayed in a format suitable for German speakers. And, if the language is neither of the two, we display the date in a format suitable for English speakers.

If you want to display text based on the user's language **and** country, you can add a a case that checks the `locale` variable. In this example we show the date in `YYYY/MM/DD` format if the uesr is in Spain, and show the date in `DD/MM/YYYY` if they are in another Spanish-speaking country:

```liquid
{% assign locale = request.locale.iso_code %}
{% assign lang = locale | split: "-" | first %}
{% if locale == "es-ES" %}
 {% render "ss-product-expiration-dates", product: product, prefix: "Consúmase antes de:", format: "%Y/%m/%d" %}
{% elsif lang == "es" %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Consúmase antes de:", format: "%d/%m/%Y" %}
{% elsif lang == "de" %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Mindestens haltbar bis:", format: "%d.%m.%Y" %}
{% else %}
  {% render "ss-product-expiration-dates", product: product, prefix: "Best by:", format: "%B %d, %Y" %}
{% endif %}
```
