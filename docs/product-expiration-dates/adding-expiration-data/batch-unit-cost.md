# Tracking a Batch's Unit Cost

Shopify’s "Cost per item" field stores one cost per variant. Updating it can erase the distinction between deliveries bought at different prices.
The Product Expiration Dates app allows one to enter a cost per batch, which allows users to accurately track delivery cost history.

You can assign values to each delivery via the "batch unit cost" field:

1. Go to the <Link path="/inventories/new">inventory batches page</Link>
1. On the Batches tab click on the cog icon:
<div><img src="/product-expiration-dates/images/inventory-batch-column-config.jpg" height="247" alt="Inventory batch column selection" /></div>
1. This will display a menu with additional fields
1. Select "Batch unit cost"
1. Click <kbd>Save</kbd>

Now the "Batch unit cost" field will be shown every time you add batches.

You can also display the batch unit cost on the inventory batches home page by following the same steps.
