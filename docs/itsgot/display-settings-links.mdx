# Linking to Web Pages from Label Nutrients


If your subscription includes <Link path="/app/plans">Premium plan features</Link> you can turn a nutrient or dietary ingredient on a label into a link to the web page of your choice.

To create a link:

1. <Link path="/nutrition_facts/new">Create</Link> or edit an existing product label
2. In the <Link path="/nutrition_facts/new#nutrients">Nutrients</Link> or <Link path="/nutrition_facts/new?label_format=supplement_vertical#dietary-ingredients">Dietary Ingredients</Link> sections, add or edit a value
3. Once a value has been entered you will see a *Display settings* link:

   <img src="/itsgot/images/product-labels-new-display-settings-link.png" width="500" alt="Display settings link" />

4. Click the link to open the *Display Settings* dialog. In the *Link* section's URL field enter the page you want to link to.
5. By default the link will open in the same page. You can have it open in a new window/tab by selecting *Open in new window/tab*.
6. Click <kbd>Save</kbd> or <kbd>Update</kbd> to save
7. Now when the label is displayed on your site a link will appear from the nutrient or dietary ingredient to the given URL

   <img src="/itsgot/images/product-labels-nutrient-linked.png" width="500" alt="Linked nutrient on label" />

To change the color of the link see the section [Changing a Label's Colors and Design](/docs/itsgot/display-settings).
