# Changelog

A summary of notable changes to It's Got.

## 2026

### August 25th

- Support for adding user-defined custom text blocks to certain label formats
- Support for changing the background color of label nutrients and dietary ingredients
- Support for adding text pills in the rich text editor
- Expand support for image uploads in the rich text editor to additional label formats
- Add option to Shopify theme editor extension to open a product label in a popup

### August 12th

- Add API endpoints for fetching product and nutrition data
- Add API endpoint to export labels to a variety of formats
- Support for product names being included on Canadian labels
- Support for "Servings per" option for US and AU labels

### August 5th

- Expand nutrient display setting options to additional label formats
- Use a rich text editor for AU allergens, claims, and warnings input fields
- Support for inserting links in the rich text editor
- Support for inserting special characters and horizontal rules in the rich text editor

### July 30th

- Add uppercase menu item option to the rich text editor to turn the selected text to uppercase
- Support for collecting product reviews
- Expand user-defined nutrient sorting to most label formats

### July 16th

- Add spacing options to percent allowance and other label elements
- Support for adding boxes around text in ingredients and claims fields

### June 17th

- Support for applying new label defaults to existing labels
- Support for global panel font size and color defaults

### March 20th

- Support for image uploads in the rich text editor

### February 25th

- Change all footnotes inputs into now rich text editors
- Support for linking nutrients and dietary ingredients to web pages
- Support for changing the appearance of dietary ingredients
- Support for setting a user-defined label headings on EU supplement facts
- Support for setting a nutrition panel's font size
- Support for adding custom nutrients in nutrition facts labels
- Support for adding asterisks to %DV/Daily Value headings

### January 29th

- Support for additional nutrition panel styling: border styles, border color, and padding
- Support for adding rich text headings to most label formats

## 2025

### December 11th

- Support for user-defined footnotes for US, supplement, UK, AU, and Canadian labels
- Support for folate and folic acid grouping
- UI to manage user-defined nutrients

### October 8th

- Support for user-defined dietary ingredient order
- Support for user-defined footnotes for UK and AU labels
- Support for batch importing of product label translations

### July 30th

- Support for user-defined nutrient order
- Support for specifying a user-defined variant selector in the Shopify theme extension

### May 22nd

- Shopify theme extension to add labels as a block via theme customization
- Support for exporting product labels as images

### April 20th

- Support for setting product label width as a percentage
- Support for user-defined nutrients for UK and AU formats
- Support for translating label text across many locales and label formats

### January 30th

- Support for displaying a product's name on the label

## 2024

### December 31st

- Support for adding defaults for product label styles
- Use a rich text editor for changing a label's heading
- Make servings on US labels optional
