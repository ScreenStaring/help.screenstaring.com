# Borders, Colors, and Indentation

:::info
You can set default values for these on <Link path="/settings/edit#label-display-settings">your account's settings page</Link>
:::

## Setting the Text Color

The color of the label and its text can be set from the Label Display Settings section. Individual text blocks and nutrients can also have their color set.

1. Find the desired product and click the "Edit" button
1. Go to the Label Display Settings section
1. Select "General"
1. Fill-in the "Text color" field with the desired color's hex color code:
   <div>
     <img src="/itsgot/shopify/images/label-set-text-color.jpg" width="700" alt="Setting a Label's Text Color" />
   </div>
1. Click <kbd>Update</kbd>
1. This will change all of the label's text to the selected color

### Text Blocks

1. From the product's page go to the desired text block
1. From the block's Format menu select "Text color"
1. You can choose a predefined color or a specific color by selecting the pallet icon:
   <div>
     <img src="/itsgot/shopify/images/label-set-text-block-color1.jpg" width="400" alt="Setting the Color of a Label's Text Block: Selection" />
   </div>
1. Click <kbd>Update</kbd>
1. The color will only be applied to the text block. The label's default color will not be affected:
   <div>
     <img src="/itsgot/shopify/images/label-set-text-block-color2.jpg" width="700" alt="Setting the Color of a Label's Text Block: Completed" />
   </div>


### Nutrients

Use a nutrient's display settings to change its color:

<img src="/itsgot/images/product-labels-new-display-settings-link.png" width="500" alt="Display settings link" />

1. From the Display Settings popup find the Style section
1. Fill-in the "Text color" field with the desired color's hex color code
1. Click <kbd>Ok</kbd>
1. Click <kbd>Update</kbd>

A background color can be set from the Label Display Settings section. Individual text blocks and nutrients can also have their background color set.

1. Find the desired product and click the "Edit" button
1. Go to the Label Display Settings section
1. Select "General"
1. Fill-in the "Text color" field with the desired color's hex color code
