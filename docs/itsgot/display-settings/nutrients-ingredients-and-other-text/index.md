# Nutrients, Ingredients, and Other Text

Display settings aren't limited to the panel as a whole. Nutrients, ingredients, and other text can each be configured individually:

- **Nutrients** - each row in the panel has a *Display settings* link where its indentation, font, color, and other style can be set
- **Ingredients and other text** - text fields, warnings, and text blocks are formatted from within the field itself using its Format menu

The options on the following pages apply to these areas:

- [Quantity Unit and Percentage](quantity-unit-and-percentage.md)
- [Folate, Folic Acid](folate-folic-acid.md)
- [Amino Acids](amino-acids.md)
