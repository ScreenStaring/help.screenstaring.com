# Quantity Unit and Percentage

By default a nutrient's value is shown without spaces, e.g. `5g` and `10%`. Spaces can be added:

:::info
You can set defaults for these on <Link path="/settings/edit#label-display-settings">your account's settings page</Link>
:::

1. Find the desired product and click the "Edit" button
1. Go to the Label Display Settings section
1. Select "Nutrition Panel"
1. Check "Add space between quantity and unit" to display `5 g`
1. Check "Add space between value and percentage" to display `10 %`
   {/* Image temporarily disabled: /itsgot/shopify/images/label-quantity-unit-percentage.jpg not available
   <div>
     <img src="/itsgot/shopify/images/label-quantity-unit-percentage.jpg" width="700" alt="Setting Quantity Unit and Percentage Spacing" />
   </div>
   */}
1. Click <kbd>Update</kbd>

The "Do not show daily value percentages" option in the same section removes the percentage column from the label entirely.
