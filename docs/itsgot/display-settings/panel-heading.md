# Panel Heading

The panel heading is the text at the top of the label, e.g. "Nutrition Facts", "Supplement Facts", "Drug Facts", or "Guaranteed Analysis".

:::info
You can set a default heading on <Link path="/settings/edit#label-display-settings">your account's settings page</Link>
:::

A label's heading can be set from the Label Display Settings section:

1. Find the desired product and click the "Edit" button
1. Go to the Label Display Settings section
1. Select "Nutrition Panel"
1. Fill-in the "Heading" field with the desired text
   {/* Image temporarily disabled: /itsgot/shopify/images/label-set-panel-heading.jpg not available
   <div>
     <img src="/itsgot/shopify/images/label-set-panel-heading.jpg" width="700" alt="Setting a Label's Panel Heading" />
   </div>
   */}
1. Click <kbd>Update</kbd>

Depending on the label's format the heading can be formatted with HTML, e.g. `<b>`, `<i>`, or a different font size.
