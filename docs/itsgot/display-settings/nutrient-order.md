# Nutrient Order

Nutrients can be listed in any order instead of the default order for the label's format:

1. Find the desired product and click the "Edit" button
1. In the label editor go to the "Nutrients" section
1. Check "Use customized order"
1. Drag the handle (⋮⋮) on a row to move it up or down
   {/* Image temporarily disabled: /itsgot/shopify/images/label-custom-nutrient-order.jpg not available
   <div>
     <img src="/itsgot/shopify/images/label-custom-nutrient-order.jpg" width="700" alt="Customizing a Label's Nutrient Order" />
   </div>
   */}
1. Click <kbd>Update</kbd>

The order is only used by the label. It doesn't change the order in which the nutrients appear anywhere else.

:::info
Custom order is not available for the "Tabular" label format.
:::
