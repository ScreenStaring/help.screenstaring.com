# Add to Product Description Button

A nutrition label can be added the top, bottom, or custom location in your product's description.
You can set one of these as the default from <Link path="/settings/edit">your account's settings page</Link>.

A custom location is typically used when the description contains tabs or an accordion and you want
the label to be added to a specific panel (see below instructions for more information).

To add a label to the product's description:

1. <Link path="/nutrition_facts/new">Create a product label</Link>. If the product already exists, locate it from the <Link path="/nutrition_facts">My Labels</Link> page and click on the product's name.

2. From the product's page locate the *Add to Product's Description* section
3. Select where you'd like to add the label: top, bottom or custom:

   <img src="/itsgot/shopify/images/nf-edit-add-to-product.jpg" alt="Add to product's description" />

   The value for custom location must be [a CSS or XPath selector](https://www.awesome-testing.com/2017/05/how-to-find-test-cssselector-using.html).

4. Click on the <kbd>Add</kbd> button

The label will be inserted into your product's description. It can take up to 1 minute for the label to appear on the product's page.

:::warning

Be careful not to remove the label's embed code when editing the product description in the Shopify Admin

:::

You can also add to your products' descriptions when [importing products in bulk](/docs/itsgot/importing-products).
