# Automatically by Adding Our Liquid Snippet to Your Theme

:::info
The best way to add product labels to your Shopify site is [via the Shopify theme editor](theme-editor).
The instructions here are only for cases that cannot be handled by the theme editor.
:::

This is a two step process: 1) add our Liquid code snippet to your theme and 2) render the snippet in the location you want the label displayed.

## Adding Our Snippet to Your Theme {/* #adding-labels-liquid-snippet-theme */}

1. <ShopifyLink href={(shopify) => shopify.toString()}>Go to the Shopify Admin</ShopifyLink>
2. [Open your theme's code editor](https://shopify.dev/docs/storefronts/themes/tools/code-editor#accessing-the-code-editor)
3. [Add a new theme file](https://shopify.dev/docs/storefronts/themes/tools/code-editor#adding-theme-files)
   - Click on the *snippets* directory
   - Click <kbd>Add new snippet</kbd>
   - For file name use `itsgot-product-label-embed-code.liquid`
   - Click <kbd>Done</kbd>
4. This will open a new blank tab in the editor named `snippets/itsgot-product-label-embed-code.liquid`
5. Copy the code from [our Liquid snippet](/itsgot/images/itsgot-product-label-embed-code.txt) and paste it into the tab
6. Click <kbd>Save</kbd>
7. Click [Add a new theme file](https://shopify.dev/docs/storefronts/themes/tools/code-editor#adding-theme-files) again
   - Click on the *snippets* directory
   - Click <kbd>Add new snippet</kbd>
   - For file name use `itsgot-product-label.liquid`
   - Click <kbd>Done</kbd>
8. This will open a new blank tab in the editor named `snippets/itsgot-product-label.liquid`
9. Copy the code from [our Liquid snippet](/itsgot/images/itsgot-product-label.txt) and paste it into the tab
10. Click <kbd>Save</kbd>

## Displaying the Product Label

Once you've [added our snippet to your theme](#adding-labels-liquid-snippet-theme) the next step is to render
it in the location you want the label displayed. This can be done from the Shopify Admin via the customize theme page.

1. <ShopifyLink href={(shopify) => shopify.themes()}>Go to *Themes* in the Shopify Admin</ShopifyLink>
2. Find the theme you want to update and click <kbd>Edit theme</kbd>
3. In the theme editor, select *Products* then *Default product* (or whatever the desired template is)
4. If you want to add the label to an existing section, click the add block button within that section and select *Custom liquid*
   or, if not available, *HTML* (note that the *HTML* block must support Liquid):

   <img src="/itsgot/shopify/images/add-liquid-block.png" width="500" alt="Add Custom liquid block" />

5. If you want to add the label to a new section, click the <kbd>Add section</kbd> button and select *Custom liquid* or *HTML*, whatever your theme provides:

   <img src="/itsgot/shopify/images/add-liquid-section.png" width="500" alt="Add Custom liquid section" />

6. If your theme does not have a *Custom liquid* nor *HTML* option, you must render the snippet in your theme manually.
   This can be done via [the theme code editor](https://shopify.dev/docs/themes/tools/code-editor).
   If you need assistance please [contact support](https://screenstaring.com/#contact).
7. Click on the *Custom liquid* block or section you just added
8. In the *Custom liquid* (or similar) field paste the following code:

   `{% render "itsgot-product-label", product: product %}`

   <img src="/itsgot/shopify/images/custom-liquid-block-contents.png" width="500" alt="Custom liquid block contents" />

9. Click <kbd>Save</kbd>

Now current and future labels will appear automatically on the products page.
