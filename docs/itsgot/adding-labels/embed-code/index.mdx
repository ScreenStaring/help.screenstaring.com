# Label Embed Code

The label embed code is an HTML snippet that allows you to add a label to any page on your site.

To add a label using the embed code:

1. <Link path="/nutrition_facts/new">Create a product label</Link>.
   If the product already exists, locate it from the <Link path="/nutrition_facts">My Labels</Link> page and click on the product's name.

2. Click the <kbd>Copy Code</kbd> button to copy the embed code to the clipboard. This
   will allow you to paste the code into your site in a later step:

   <img src="/itsgot/shopify/images/nf-edit-embed-code.jpg" alt="Copy embed code" />

3. Select where you want to add your snippet. The screenshot below uses Blog Posts and Pages
   but these instructions apply to Collections and Products too:

   <img src="/itsgot/shopify/images/shopify-select-page.jpg" alt="Select page in Shopify admin" />

4. Select an existing blog post (or page, collection, or product) you'd like to add the label to.
   If the blog post does not exist add a new one:

   <img src="/itsgot/shopify/images/shopify-select-entry.jpg" alt="Select blog entry" />

5. Find the location in the content area that you want your product label to be displayed in. Since you will be switching
   to HTML mode to insert the embed code, it's a good idea to insert some marker text that you can then replace.
   In this case we added the text *REPLACE ME*:

   <img src="/itsgot/shopify/images/shopify-blog-replace-me.jpg" alt="Insert REPLACE ME marker text" />

6. Click the button to edit in HTML mode:

   <img src="/itsgot/shopify/images/shopify-blog-select-html.jpg" alt="Select HTML mode" />

7. The Content area now shows HTML code:

   <img src="/itsgot/shopify/images/shopify-blog-edit-html.jpg" alt="Content area in HTML mode" />

8. Remove the *REPLACE ME* text and paste in the embed code copied in step 2:

   <img src="/itsgot/shopify/images/shopify-blog-insert-snippet.jpg" alt="Paste embed code" />

9. To complete, click the <kbd>Save</kbd> button:

   <img src="/itsgot/shopify/images/shopify-blog-save-snippet.jpg" alt="Save blog post" />

The product's label is now part of the blog post.
