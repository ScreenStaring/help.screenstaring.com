# Adding Nutrition Labels to Your Site

There are several ways to add nutrition labels to your site.

## Shopify

If you're using Shopify install our [Nutrition Facts Shopify App](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

The majority of Shopify users should use the Shopify Theme editor to add the nutrition labels.

- [Shopify Theme Editor](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Add to Product's Description button](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Label Embed Code

The embed code can be used to make a product's label appear anywhere.

- [Label Embed Code](/docs/itsgot/adding-labels/embed-code)
You can also use the [Combine API](/docs/itsgot/combine-api).
