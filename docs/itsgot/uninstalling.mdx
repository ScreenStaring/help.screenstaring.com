# Uninstalling the App


Before uninstalling the app existing product labels must be removed.
This includes:

1. Labels automatically added to your product descriptions
2. Labels manually added via embed code

## Labels Automatically Added to Your Product Descriptions

These labels can be removed by deleting all of your labels. To do this:

1. Visit the <Link path="/nutrition_facts">My Labels</Link> page
2. For each label that was automatically added, click on its <kbd>Delete</kbd> button:

   <img src="/itsgot/shopify/images/nf-index-delete-product.jpg" alt="Delete product label" />

If you need help <SupportEmail subject="Remove Product Labels">contact our support team</SupportEmail>.

## Labels Manually Added via Embed Code

Embed code that you've manually added to your site will not be automatically removed. You must do this yourself.
If you need help <SupportEmail subject="Remove Product Labels">contact our support team</SupportEmail>.
