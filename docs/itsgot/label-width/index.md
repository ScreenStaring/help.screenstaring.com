# Setting a Label's Width

The width of a label can be:

- A fixed pixel value
- A percentage of its parent HTML element's size
- Vary by a user's device e.g., tablet vs desktop

Fixed and percentage widths can be set via a label's the "Width" field, located in the Label Display Setting's General section.
The width field is composed of a the width's value and its unit:

<div>
    <img src="/itsgot/images/label-width-value-and-unit-field.jpg" width="500" alt="Using the Label's Width Field" />
</div>

The unit can be either pixels (`px`) or a percentage (`%`).

A default width can be set on <Link path="/settings/edit#label-display-settings">your account's settings page</Link>.

Each option is described on the following pages:

- [Fixed pixel value](fixed-pixel-value.md)
- [Percentage of its parent HTML element's size](percentage-of-its-parent-html-elements-size.md)
- [Vary by a user's device](vary-by-a-users-device.md)
