# Translating Label Text


Label text can be changed by creating a <Link path="/app/translations">translation</Link>.
Translations can be used to change all text on the label. It's not strictly for translating between languages.

Using Translations requires [setting the label's locale](/docs/itsgot/multi-language#multi-language-label-locale).
Once set translations can be created for that locale that match the source text, and replace it with the user-defined text.

Translating block text like ingredients and warnings can be done on the label's edit page in the *Translations* section.
See [Translating Ingredients and Other Block Text](/docs/itsgot/multi-language#multi-language-label-translations).
