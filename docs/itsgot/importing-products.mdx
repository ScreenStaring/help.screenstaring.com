# Importing Products in Bulk


To import your products in bulk:

1. [Download our CSV template](/itsgot/images/product-import-template.csv)
2. Add your product and nutrition data
3. Go to the <Link path="/products/import/new">Product Import</Link> page and upload your CSV file
4. Note that the sample spreadsheet does not contain all possible nutrients, see [Adding Nutrients to the Spreadsheet](#adding-nutrients-to-the-spreadsheet)

The CSV template requires values for the following columns:

- **Label Format**
  Must be one of:

  - `ca:legacy:nutrition_facts:vertical`
  - `de:eu:nutrition_facts:vertical`
  - `dk:eu:nutrition_facts:vertical`
  - `se:eu:nutrition_facts:vertical`
  - `uk:eu:nutrition_facts:vertical`
  - `us:2016:nutrition_facts:tabular`
  - `us:2016:nutrition_facts:vertical`
  - `us:2016:nutrition_facts:emblems`
  - `us:legacy:nutrition_facts:vertical`
  - `us:legacy:supplement_facts:vertical_columns`
  - `us:legacy:supplement_facts:vertical`
  - `us:2016:supplement_facts:vertical_columns`
  - `us:2016:supplement_facts:vertical`

- **A product identifier column**
  Must be one of: Product ID/Variant ID or SKU. These will be used to associate the product with a matching Shopify product.

## Adding Nutrients to the Spreadsheet {/* #adding-nutrients-to-the-spreadsheet */}

Any nutrient can be imported. For example, to import Omega 3 with a quantity of 1000mg you'd add an *Omega 3* column with a value of *1000mg* for the given product's row.
If you wanted to specify a percent allowance you'd add a column *Omega 3 %*:

## Nutrition Data With Multiple Servings
