# Integração via API


**A integração via API está disponível apenas no <Link path="/app/plans">plano Premium</Link>.**

Os pedidos à API são autenticados utilizando a sua chave de API.
Inclua a sua chave de API no cabeçalho `X-API-Key` em cada pedido.
Contacte o apoio para obter a sua.

## URL Base

Todos os endpoints da API são relativos a: `https://itsgot.com`

## Paginação

Para endpoints que suportem paginação, os URLs da página seguinte e da página anterior podem ser consultados no cabeçalho `Link` da resposta HTTP.

## Obter Produtos

### GET /api/products

**Parâmetros de Consulta:**

- `sku` - O SKU da variante (opcional)
- `barcode` - O código de barras da variante (opcional)
- `external_product_id` - ID do produto na Shopify (opcional)
- `external_variant_id` - ID da variante na Shopify (opcional)
- `page` - Página a obter (opcional)
- `per_page` - Número de produtos devolvidos por página; tem de ser um dos seguintes: `10`, `25`, `50`, `100` (opcional, a predefinição é 10)

**Exemplo utilizando curl:**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products?sku=JARFOOD'
```

## Exportar um Rótulo para um Formato Específico

### GET /api/products/PRODUCT_ID/labels/LABEL_ID/export.FORMAT

**Parâmetros obrigatórios:**

- `PRODUCT_ID` - ID do produto cujo rótulo pretende exportar
- `LABEL_ID` - ID do rótulo que pretende exportar
- `FORMAT` - Formato para exportar. Um dos seguintes: `png`, `jpg`, `pdf` ou `html`

**Parâmetros de consulta opcionais:**

- `width` - Apenas para imagens. Exporta o rótulo com a largura indicada. A predefinição é a largura do rótulo x 2.
- `height` - Apenas para imagens. Exporta o rótulo com a altura indicada. Por predefinição, a proporção é mantida e a altura baseia-se na largura indicada.
- `background_color` - Apenas para imagens. Cor de fundo a utilizar se o rótulo for redimensionado e deixar de manter a sua proporção

**Exemplo utilizando curl:**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products/123/labels/789/export.jpg' > product.jpg
```
