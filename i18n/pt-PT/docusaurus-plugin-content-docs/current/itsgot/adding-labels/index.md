# Adicionar Rótulos Nutricionais ao Seu Site

Existem várias formas de adicionar rótulos nutricionais ao seu site.

## Shopify

Se utiliza a Shopify, instale a nossa [aplicação Nutrition Facts para a Shopify](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

A maioria dos utilizadores da Shopify deve utilizar o editor de temas da Shopify para adicionar os rótulos nutricionais.

- [Editor de Temas da Shopify](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Botão Adicionar à descrição do produto](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Código de Incorporação do Rótulo

O código de incorporação pode ser utilizado para fazer com que o rótulo de um produto seja apresentado em qualquer lugar.

- [Código de Incorporação do Rótulo](/docs/itsgot/adding-labels/embed-code)
Também pode utilizar a [API Combine](/docs/itsgot/combine-api).
