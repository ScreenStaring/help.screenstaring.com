# Traduzir o Texto dos Rótulos


O texto do rótulo pode ser alterado criando uma <Link path="/app/translations">tradução</Link>.
As traduções podem ser utilizadas para alterar qualquer texto no rótulo, não servindo estritamente para traduzir entre diferentes idiomas.

A utilização de Traduções exige a [definição do locale do rótulo](/docs/itsgot/multi-language#multi-language-label-locale).
Uma vez definido, podem ser criadas traduções para esse locale que correspondam ao texto de origem, substituindo-o pelo texto personalizado do utilizador.

A tradução de texto de blocos, como ingredientes e avisos, pode ser efetuada na página de edição do rótulo, na secção *Traduções*.
Consulte [Traduzir Ingredientes e Outro Texto de Bloco](/docs/itsgot/multi-language#multi-language-label-translations).
