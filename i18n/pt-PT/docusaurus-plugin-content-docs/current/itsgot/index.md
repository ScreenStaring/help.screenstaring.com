O [It's Got](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link) gere os dados nutricionais dos produtos e permite
adicionar painéis de informação nutricional, de suplementos, de medicamentos e para animais de estimação ao seu site.
Os rótulos podem ser gerados em formatos conhecidos para vários países e idiomas.
