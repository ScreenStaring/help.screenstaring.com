# Ordem dos Nutrientes

Os nutrientes podem ser listados em qualquer ordem em vez da ordem predefinida do formato de rótulo:

1. Localize o produto pretendido e clique no botão "Editar"
1. No editor de rótulos, aceda à secção "Nutrientes"
1. Ative a opção "Utilizar ordem personalizada"
1. Arraste a alça (⋮⋮) numa linha para a mover para cima ou para baixo
   {/* Image temporarily disabled: /itsgot/shopify/images/label-custom-nutrient-order.jpg not available
   <div>
     <img src="/itsgot/shopify/images/label-custom-nutrient-order.jpg" width="700" alt="Personalizar a ordem dos nutrientes do rótulo" />
   </div>
   */}
1. Clique em <kbd>Atualizar</kbd>

A ordem é utilizada apenas pelo rótulo. Não altera a ordem pela qual os nutrientes são apresentados em qualquer outro local.

:::info
A ordem personalizada não está disponível para o formato de rótulo "Tabular".
:::
