# Notificaciones, impresión de pedidos y documentos de empaque

Esto te permite agregar fechas de vencimiento y números de lote a:

-   [Notificaciones de Shopify](https://www.shopify.com/admin/settings/notifications) (de forma predeterminada no se aplica a la confirmación del pedido, ya que el correo se envía antes de que se asigne el lote)
-   [Order Printer](https://apps.shopify.com/order-printer) y [Shopify Order Printer](https://apps.shopify.com/shopify-order-printer)
-   [Order Printer Pro](https://apps.shopify.com/order-printer-pro)
-   [Aplicación Multi-Label Barcodes](https://apps.shopify.com/multi-label-barcodes)
-   ¡Y mucho más!

Para comenzar, debes activar las notas del pedido <Link path="/settings#orders">desde la página de configuración</Link> seleccionando "Crear una entrada de 'detalles adicionales' del pedido para la integración con aplicaciones de terceros". Una vez activado, genera un fragmento de código a continuación para tu integración.

## Fragmento de código

El fragmento de código resultante se puede agregar a la plantilla de Liquid correspondiente para tu integración, en la ubicación donde quieres que se muestren los datos de vencimiento. Este fragmento funciona **con** la plantilla existente para mostrar los datos de vencimiento. No está pensado para reemplazarla.

Si no ves tu integración en la lista y necesitas ayuda, contacta al soporte.

```liquid
{% comment %}
  Code for the Product Expiration Dates app to display a product's expiration date and related
  informtion in notifications, order printing, & packing slips.

  If you want to hide the expiration date until it's close to a particular number of days
  set the expires_window_days variable below to the number of desired days instead of blank.
  For example:

    {% assign expires_window_days = 30 %}

  For assistance contact support at help@screenstaring.com
{% endcomment %}

{% assign expires_window_days = blank %}

{% capture key %}Expiration Dates {{ line_item.sku }}{% endcapture %}
{% if attributes[key] != blank %}
    {% assign batches = attributes[key] | split: "|" %}
    {% for batch in batches %}
        {% assign batch_data = batch | split: "," %}
        {% assign expires_date = batch_data[0] %}
        {% assign expires_qty = batch_data[1] %}
        {% assign expires_batch = batch_data[2] %}

        {% assign now = "now" | date: "%s" %}
        {% assign seconds_in_a_day = 86400 %}
        {% assign expires_at = expires_date | date: "%s" | plus: seconds_in_day | minus: 1 %}
        {% assign diff = expires_at | minus: now | divided_by: seconds_in_a_day %}
        {% assign show_date = false %}

        {% if expires_window_days == blank  %}
          {% assign show_date = true %}
        {% elsif diff >= 0 and diff < expires_window_days %}
          {% assign show_date = true %}
        {% endif %}

        {% if show_date %}
          {% comment %}
            The date format can be adjust by changing the '%d/%m/%Y' portion below
            to the desired date format codes. See: https://shopify.dev/api/liquid/filters#date
            To use a tranlated date see: https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files
          {% endcomment %}
          Expires:
          {{ expires_date | date: "%d/%m/%Y" }}

          {% comment %}
            Remove the following if you do not want the quantity and batch name displayed
          {% endcomment %}
          ({{ expires_qty }})
          {% if expires_batch != blank %}
              {{ expires_batch }}
          {% endif %}
        {% endif %}
    {% endfor %}
{% endif %}
```

Es posible que tengas que cambiar la variable `line_item` o `line` para que coincida con la que se usa en tu código existente.

El formato de fecha se basa en el [filtro `date` de Liquid](https://shopify.dev/api/liquid/filters#date). Se puede ajustar cambiando la parte `"%d/%m/%Y"` para usar los códigos de formato de fecha que quieras. Consulta la documentación del filtro `date` para ver la lista. Para usar una fecha traducida, especifica un formato de fecha [de los archivos de configuración regional de tu tema](https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files). Por ejemplo, si el formato `month_day_year` existiera (puede que sí), puedes cambiar:

```liquid
{{ expires_date | date: "%d/%m/%Y" }}
```

En el fragmento anterior, a:

```liquid
{{ expires_date | date: format: "month_day_year" }}
```

## Detalles técnicos

Se agregará un atributo al pedido por cada artículo del pedido. El atributo se llamará `"Expiration Dates [ID]"`, donde `[ID]` es el SKU, el código de barras o el ID de variante de Shopify del artículo del pedido. Lo que se use depende de la configuración de tu tienda. Si usas SKUs, siempre será el SKU. Si solo usas el código de barras, será el código de barras, etc...

El valor del atributo es una cadena separada por comas que contiene la fecha de vencimiento asignada, la cantidad y el número de lote:

```
2023-04-22,2,BATCH-NUMBER
```

Si hay varias asignaciones para un artículo del pedido, cada asignación estará separada por el carácter de barra vertical (`|`):

```
2023-04-22,2,BATCH-NUMBER-1|2023-12-25,1,BATCH-NUMBER-2
```
