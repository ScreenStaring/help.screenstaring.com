# Importar datos de vencimiento de forma masiva

Puedes importar varias fechas de vencimiento y cantidades mediante nuestro archivo CSV de importación de lotes. Encontrarás un ejemplo [aquí](/product-expiration-dates/images/product-expiration-dates-import-template.csv).

Las columnas «SKU», «Expiration Date», «Quantity» y «Location Name» son obligatorias. **Las fechas de vencimiento deben proporcionarse en el formato `YYYY-MM-DD`.** Para utilizar «Barcode» en lugar de «SKU», selecciona «Identificar filas por código de barras» en la página de importación de lotes.

Para obtener más información sobre la columna «Allocate Quantities to Orders When», consulta [Agregar datos de vencimiento a los productos](/docs/product-expiration-dates/adding-expiration-data).

El archivo CSV debe utilizar la codificación UTF-8 y la coma (`,`) como separador de campos.

Cuando el archivo esté listo, súbelo desde <Link path="/import">la página de importación</Link>.
