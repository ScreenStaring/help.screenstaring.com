# Compartir inventario entre varias tiendas

Si tu inventario abastece a varias tiendas, estas tiendas se pueden vincular. Vincular tiendas permite compartir un único conjunto de datos de vencimiento entre varias tiendas.

Para vincular tiendas, debes:

-   Instalar la aplicación en cada tienda (después del período de prueba, todas las tiendas deben tener una suscripción activa)
-   Usar los mismos SKU de producto en cada tienda (si lo prefieres, puedes usar el código de barras en su lugar)
-   Si usas ubicaciones, usa los mismos nombres de ubicación en cada tienda
-   [Contacta a soporte](https://screenstaring.com/#contact) para crear el vínculo o los vínculos
