# Cambiar el formato de fecha y hora

El formato de fecha que se muestra en la aplicación depende de tu configuración regional. Puedes cambiar tu configuración regional en la <Link path="/settings#general">pestaña General de la página de configuración</Link>. De forma predeterminada, usamos la configuración regional proporcionada por Shopify. Cambiar la configuración regional no afecta las fechas de vencimiento de los lotes de inventario. Solo cambia el formato que se usa para mostrarlas.

El formato de fecha que se muestra en tu sitio se puede configurar al [agregar datos de vencimiento a tu sitio](/docs/product-expiration-dates/shopify-pages).
