# Entrada mediante escáner de códigos de barras

Mejora la eficiencia de la recepción de inventario y de la asignación de lotes escaneando el código de barras de un producto en lugar de buscarlo manualmente por nombre, SKU o código de barras.

Para comenzar, instala la [aplicación Barcode Scanner](https://apps.shopify.com/barcode-scanner-1?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

La aplicación Barcode Scanner debe utilizarse desde la [aplicación móvil de Shopify](https://www.shopify.com/mobile).
