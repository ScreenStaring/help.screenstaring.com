# Entrada mediante escáner de código de barras

Mejora la eficiencia de la recepción de inventario y de la asignación de lotes de inventario escaneando el código de barras de un producto en lugar de tener que buscar el producto escribiendo su nombre, SKU o código de barras.
Para comenzar, instala [la aplicación Barcode Scanner](https://apps.shopify.com/barcode-scanner-1?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).
La aplicación Barcode Scanner debe usarse desde [la aplicación Shopify Mobile](https://www.shopify.com/mobile).
