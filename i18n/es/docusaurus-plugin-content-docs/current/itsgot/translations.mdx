# Traducir el texto de las etiquetas


El texto de una etiqueta se puede cambiar creando una <Link path="/app/translations">traducción</Link>.
Las traducciones se pueden usar para cambiar todo el texto de la etiqueta. No son estrictamente para traducir entre idiomas.

Usar traducciones requiere [establecer la configuración regional de la etiqueta](/docs/itsgot/multi-language#multi-language-label-locale).
Una vez establecida, se pueden crear traducciones para esa configuración regional que coincidan con el texto de origen y lo reemplacen con el texto definido por el usuario.

La traducción de bloques de texto como ingredientes y advertencias se puede hacer en la página de edición de la etiqueta, en la sección *Traducciones*.
Consulta [Traducir ingredientes y otros bloques de texto](/docs/itsgot/multi-language#multi-language-label-translations).
