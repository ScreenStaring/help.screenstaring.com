# Código de inserción de etiquetas

El código de inserción de etiquetas es un fragmento de HTML que te permite agregar una etiqueta a cualquier página de tu sitio.

Para agregar una etiqueta con el código de inserción:

1. <Link path="/nutrition_facts/new">Crea una etiqueta de producto</Link>.
   Si el producto ya existe, búscalo en la página <Link path="/nutrition_facts">Mis etiquetas</Link> y haz clic en el nombre del producto.

2. Haz clic en el botón <kbd>Copiar código</kbd> para copiar el código de inserción al portapapeles. Esto
   te permitirá pegar el código en tu sitio en un paso posterior:

   <img src="/itsgot/shopify/images/nf-edit-embed-code.jpg" alt="Copiar código de inserción" />

3. Selecciona dónde quieres agregar tu fragmento. La captura de pantalla a continuación usa Entradas del blog y Páginas,
   pero estas instrucciones también se aplican a Colecciones y Productos:

   <img src="/itsgot/shopify/images/shopify-select-page.jpg" alt="Selecciona la página en el administrador de Shopify" />

4. Selecciona una entrada de blog existente (o página, colección o producto) a la que quieras agregar la etiqueta.
   Si la entrada de blog no existe, crea una nueva:

   <img src="/itsgot/shopify/images/shopify-select-entry.jpg" alt="Selecciona la entrada del blog" />

5. Busca la ubicación dentro del área de contenido donde quieres que se muestre la etiqueta de tu producto. Como
   cambiarás al modo HTML para insertar el código de inserción, es buena idea insertar un texto marcador que puedas
   reemplazar después. En este caso, agregamos el texto *REPLACE ME*:

   <img src="/itsgot/shopify/images/shopify-blog-replace-me.jpg" alt="Inserta el texto marcador REPLACE ME" />

6. Haz clic en el botón para editar en modo HTML:

   <img src="/itsgot/shopify/images/shopify-blog-select-html.jpg" alt="Selecciona el modo HTML" />

7. El área de Contenido ahora muestra el código HTML:

   <img src="/itsgot/shopify/images/shopify-blog-edit-html.jpg" alt="Área de contenido en modo HTML" />

8. Elimina el texto *REPLACE ME* y pega el código de inserción que copiaste en el paso 2:

   <img src="/itsgot/shopify/images/shopify-blog-insert-snippet.jpg" alt="Pega el código de inserción" />

9. Para terminar, haz clic en el botón <kbd>Guardar</kbd>:

   <img src="/itsgot/shopify/images/shopify-blog-save-snippet.jpg" alt="Guardar la entrada del blog" />

La etiqueta del producto ahora es parte de la entrada del blog.
