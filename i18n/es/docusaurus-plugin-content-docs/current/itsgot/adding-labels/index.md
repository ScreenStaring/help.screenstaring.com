# Agregar etiquetas nutricionales a tu sitio

Hay varias formas de agregar etiquetas nutricionales a tu sitio.

## Shopify

Si usas Shopify, instala nuestra [aplicación Nutrition Facts para Shopify](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

La mayoría de los usuarios de Shopify debería usar el editor de temas de Shopify para agregar las etiquetas nutricionales.

- [Editor de temas de Shopify](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Botón Agregar a la descripción del producto](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Código de inserción de etiquetas

El código de inserción se puede usar para hacer que la etiqueta de un producto aparezca en cualquier lugar.

- [Código de inserción de etiquetas](/docs/itsgot/adding-labels/embed-code)
También puedes usar la [Combine API](/docs/itsgot/combine-api).
