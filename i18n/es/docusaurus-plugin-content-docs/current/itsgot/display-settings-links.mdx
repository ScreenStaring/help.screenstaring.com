# Enlazar a páginas web desde los nutrientes de la etiqueta


Si tu suscripción incluye <Link path="/app/plans">funciones del plan Premium</Link> puedes convertir un nutriente o un ingrediente dietético de una etiqueta en un enlace a la página web que quieras.

Para crear un enlace:

1. <Link path="/nutrition_facts/new">Crea</Link> o edita la etiqueta de un producto existente
2. En las secciones <Link path="/nutrition_facts/new#nutrients">Nutrientes</Link> o <Link path="/nutrition_facts/new?label_format=supplement_vertical#dietary-ingredients">Ingredientes dietéticos</Link>, agrega o edita un valor
3. Una vez que se haya ingresado un valor, verás un enlace *Configuración de visualización*:

   <img src="/itsgot/images/product-labels-new-display-settings-link.png" width="500" alt="Enlace de configuración de visualización" />

4. Haz clic en el enlace para abrir el cuadro de diálogo *Configuración de visualización*. En el campo URL de la sección *Enlace*, ingresa la página a la que quieres enlazar.
5. De forma predeterminada, el enlace se abrirá en la misma página. Puedes hacer que se abra en una ventana o pestaña nueva seleccionando *Abrir en ventana/pestaña nueva*.
6. Haz clic en <kbd>Guardar</kbd> o <kbd>Actualizar</kbd> para guardar
7. Ahora, cuando la etiqueta se muestre en tu sitio, aparecerá un enlace desde el nutriente o el ingrediente dietético hacia la URL indicada

   <img src="/itsgot/images/product-labels-nutrient-linked.png" width="500" alt="Nutriente enlazado en la etiqueta" />

Para cambiar el color del enlace, consulta la sección [Modificar el diseño de una etiqueta](/docs/itsgot/display-settings).
