# Nutrientes, ingredientes y otros textos

La configuración de visualización no se limita al panel en su conjunto. Los nutrientes, los ingredientes y otros textos se pueden configurar individualmente:

- **Nutrientes** - cada fila del panel tiene un enlace *Configuración de visualización* donde se pueden establecer su sangría, fuente, color y otros estilos
- **Ingredientes y otros textos** - los campos de texto, las advertencias y los bloques de texto se formatean desde el propio campo usando su menú Formato

Las opciones de las siguientes páginas se aplican a estas áreas:

- [Cantidad, unidad y porcentaje](quantity-unit-and-percentage.md)
- [Folato, ácido fólico](folate-folic-acid.md)
- [Aminoácidos](amino-acids.md)
