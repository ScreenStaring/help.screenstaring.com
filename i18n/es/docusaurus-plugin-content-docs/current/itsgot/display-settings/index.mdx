# Modificar el diseño de una etiqueta

La configuración se aplica en 2 niveles:

1. Valores predeterminados del sitio que se aplican a todas las etiquetas nuevas
2. Valores específicos de cada etiqueta

Los valores predeterminados del sitio se pueden configurar en <Link path="/settings/edit#label-display-settings">la página de configuración de tu cuenta</Link>.

Los valores específicos de cada etiqueta se pueden establecer al crear o editar una etiqueta en la <Link path="/nutrition_facts/new#label-display-settings">sección Configuración de visualización de la etiqueta</Link>.
Esta configuración se divide en:

1. **General** - Configuración básica que se aplica a todo en la etiqueta. Ancho, tamaño de la fuente, etc.
2. **Panel de información nutricional** - Configuración que se aplica específicamente al panel. Tamaño del borde, color, grosor, etc.
3. **CSS personalizado** - CSS específico del sitio para incluir en todas las etiquetas nuevas

Los colores y el diseño de los campos de texto, como los ingredientes y las advertencias, se pueden modificar dentro del propio campo.

La configuración también se puede establecer por fila en el panel de información nutricional. Esto incluye cosas como cambiar la sangría de un nutriente, poner su texto en negrita,
y agregar enlaces a otros productos o páginas de tu sitio. Para configurar un ajuste de una fila, haz clic en el enlace *Configuración de visualización* después de
seleccionar o ingresar un valor:
