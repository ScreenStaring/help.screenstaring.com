# Historial de cambios

Un resumen de los cambios notables en It's Got.

## 2026

### 25 de agosto

- Soporte para agregar bloques de texto personalizados definidos por el usuario a ciertos formatos de etiqueta
- Soporte para cambiar el color de fondo de los nutrientes de la etiqueta y los ingredientes dietéticos
- Soporte para agregar píldoras de texto en el editor de texto enriquecido
- Ampliación del soporte para cargar imágenes en el editor de texto enriquecido a más formatos de etiqueta
- Opción en la extensión del editor de temas de Shopify para abrir la etiqueta de un producto en una ventana emergente

### 12 de agosto

- Endpoints de la API para obtener datos de productos y de nutrición
- Endpoint de la API para exportar etiquetas a varios formatos
- Soporte para incluir nombres de productos en las etiquetas canadienses
- Soporte para la opción "Porciones por" en etiquetas de EE. UU. y Australia

### 5 de agosto

- Ampliación de las opciones de configuración de visualización de nutrientes a más formatos de etiqueta
- Uso de un editor de texto enriquecido en los campos de entrada de alérgenos, declaraciones y advertencias de Australia
- Soporte para insertar enlaces en el editor de texto enriquecido
- Soporte para insertar caracteres especiales y líneas horizontales en el editor de texto enriquecido

### 30 de julio

- Opción de menú de mayúsculas en el editor de texto enriquecido para convertir el texto seleccionado a mayúsculas
- Soporte para recopilar reseñas de productos
- Ampliación del ordenamiento de nutrientes definido por el usuario a la mayoría de los formatos de etiqueta

### 16 de julio

- Opciones de espaciado para el porcentaje permitido y otros elementos de la etiqueta
- Soporte para agregar recuadros alrededor del texto en los campos de ingredientes y declaraciones

### 17 de junio

- Soporte para aplicar nuevos valores predeterminados de etiqueta a las etiquetas existentes
- Soporte para valores predeterminados globales de tamaño de fuente y color del panel

### 20 de marzo

- Soporte para cargar imágenes en el editor de texto enriquecido

### 25 de febrero

- Conversión de todos los campos de entrada de notas al pie en editores de texto enriquecido
- Soporte para enlazar nutrientes e ingredientes dietéticos a páginas web
- Soporte para cambiar la apariencia de los ingredientes dietéticos
- Soporte para establecer encabezados de etiqueta definidos por el usuario en los datos de suplementos de la UE
- Soporte para establecer el tamaño de fuente de un panel de información nutricional
- Soporte para agregar nutrientes personalizados en las etiquetas de información nutricional
- Soporte para agregar asteriscos a los encabezados %DV/Valor diario

### 29 de enero

- Soporte para estilos adicionales del panel de información nutricional: estilos de borde, color de borde y relleno
- Soporte para agregar encabezados de texto enriquecido a la mayoría de los formatos de etiqueta

## 2025

### 11 de diciembre

- Soporte para notas al pie definidas por el usuario en etiquetas de EE. UU., suplementos, el Reino Unido, Australia y Canadá
- Soporte para agrupar folato y ácido fólico
- Interfaz de usuario para gestionar nutrientes definidos por el usuario

### 8 de octubre

- Soporte para el orden de ingredientes dietéticos definido por el usuario
- Soporte para notas al pie definidas por el usuario en etiquetas del Reino Unido y Australia
- Soporte para la importación por lotes de traducciones de etiquetas de productos

### 30 de julio

- Soporte para el orden de nutrientes definido por el usuario
- Soporte para especificar un selector de variantes definido por el usuario en la extensión del tema de Shopify

### 22 de mayo

- Extensión del tema de Shopify para agregar etiquetas como bloque mediante la personalización del tema
- Soporte para exportar etiquetas de productos como imágenes

### 20 de abril

- Soporte para establecer el ancho de la etiqueta de un producto como porcentaje
- Soporte para nutrientes definidos por el usuario en los formatos del Reino Unido y Australia
- Soporte para traducir el texto de las etiquetas en muchas configuraciones regionales y formatos de etiqueta

### 30 de enero

- Soporte para mostrar el nombre de un producto en la etiqueta

## 2024

### 31 de diciembre

- Soporte para agregar valores predeterminados para los estilos de las etiquetas de productos
- Uso de un editor de texto enriquecido para cambiar el encabezado de una etiqueta
- Las porciones en las etiquetas de EE. UU. ahora son opcionales
