# Integración con la API


**La integración con la API solo está disponible en el <Link path="/app/plans">plan Premium</Link>.**

Las solicitudes a la API se autentican con tu clave de API.
Incluye tu clave de API en el encabezado `X-API-Key` en cada solicitud.
Contacta a soporte para obtener la tuya.

## URL base

Todos los endpoints de la API son relativos a: `https://itsgot.com`

## Paginación

En los endpoints que admiten paginación, las URL de la página siguiente y de la página anterior se encuentran en el encabezado `Link` de HTTP.

## Obtener productos

### GET /api/products

**Parámetros de consulta:**

- `sku` - El SKU de la variante (opcional)
- `barcode` - El código de barras de la variante (opcional)
- `external_product_id` - ID del producto de Shopify (opcional)
- `external_variant_id` - ID de la variante de Shopify (opcional)
- `page` - Página que se va a obtener (opcional)
- `per_page` - Cantidad de productos devueltos por página, debe ser uno de `10`, `25`, `50`, `100` (opcional, el valor predeterminado es 10)

**Ejemplo con curl:**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products?sku=JARFOOD'
```

## Exportar una etiqueta a un formato específico

### GET /api/products/PRODUCT_ID/labels/LABEL_ID/export.FORMAT

**Parámetros requeridos:**

- `PRODUCT_ID` - ID del producto de la etiqueta que quieres exportar
- `LABEL_ID` - ID de la etiqueta que quieres exportar
- `FORMAT` - Formato de exportación. Uno de `png`, `jpg`, `pdf` o `html`

**Parámetros de consulta opcionales:**

- `width` - Solo para imágenes. Exporta la etiqueta con el ancho indicado. El valor predeterminado es el ancho de la etiqueta x 2.
- `height` - Solo para imágenes. Exporta la etiqueta con el alto indicado. De forma predeterminada, se mantiene la relación de aspecto y el alto se basa en el ancho indicado.
- `background_color` - Solo para imágenes. Color de fondo que se usa si la etiqueta se redimensiona y ya no mantiene su relación de aspecto

**Ejemplo con curl:**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products/123/labels/789/export.jpg' > product.jpg
```
