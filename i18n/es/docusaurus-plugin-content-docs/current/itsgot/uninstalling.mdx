# Desinstalar la aplicación


Antes de desinstalar la aplicación, se deben eliminar las etiquetas de productos existentes.
Esto incluye:

1. Etiquetas agregadas automáticamente a las descripciones de tus productos
2. Etiquetas agregadas manualmente mediante código de inserción

## Etiquetas agregadas automáticamente a las descripciones de tus productos

Estas etiquetas se pueden eliminar borrando todas tus etiquetas. Para hacerlo:

1. Visita la página <Link path="/nutrition_facts">Mis etiquetas</Link>
2. Para cada etiqueta que se agregó automáticamente, haz clic en su botón <kbd>Eliminar</kbd>:

   <img src="/itsgot/shopify/images/nf-index-delete-product.jpg" alt="Eliminar etiqueta de producto" />

Si necesitas ayuda, <SupportEmail subject="Eliminar etiquetas de productos">contacta a nuestro equipo de soporte</SupportEmail>.

## Etiquetas agregadas manualmente mediante código de inserción

El código de inserción que agregaste manualmente a tu sitio no se eliminará automáticamente. Debes hacerlo tú mismo.
Si necesitas ayuda, <SupportEmail subject="Eliminar etiquetas de productos">contacta a nuestro equipo de soporte</SupportEmail>.
