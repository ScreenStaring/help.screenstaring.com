# Gemeinsame Bestandsnutzung zwischen mehreren Shops

Wenn Ihr Warenbestand mehrere Shops versorgt, können diese miteinander verknüpft werden. Das Verknüpfen von Shops ermöglicht es, einen einzigen gemeinsamen Satz an Ablaufdaten über mehrere Shops hinweg zu nutzen.

Voraussetzungen für die Verknüpfung von Shops:

-   Installieren Sie die App in jedem Shop (nach Ablauf der Testphase müssen alle Shops über ein aktives Abonnement verfügen)
-   Verwenden Sie in allen Shops dieselben Produkt-SKUs (alternativ können Sie stattdessen auch Barcodes verwenden)
-   Falls Sie Standorte verwenden, müssen die Standortnamen in allen Shops exakt übereinstimmen
-   [Wenden Sie sich an den Support](https://screenstaring.com/#contact), um die Verknüpfung(en) einrichten zu lassen
