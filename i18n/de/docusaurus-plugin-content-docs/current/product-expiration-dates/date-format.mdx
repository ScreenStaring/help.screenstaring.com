# Datums- und Uhrzeitformat ändern

Das in der App angezeigte Datumsformat richtet sich nach Ihrem Gebietsschema (Locale). Ihr Gebietsschema kann auf der <Link path="/settings#general">Registerkarte „Allgemeines“ der Einstellungsseite</Link> geändert werden. Standardmäßig verwenden wir das von Shopify bereitgestellte Gebietsschema. Das Ändern des Gebietsschemas hat keinen Einfluss auf die gespeicherten Ablaufdaten der Bestandschargen. Es ändert lediglich das für die Anzeige verwendete Format.

Das auf Ihrer Website angezeigte Datumsformat kann bei der [Einbindung von Ablaufdaten auf Ihrer Website](/docs/product-expiration-dates/shopify-pages) konfiguriert werden.
