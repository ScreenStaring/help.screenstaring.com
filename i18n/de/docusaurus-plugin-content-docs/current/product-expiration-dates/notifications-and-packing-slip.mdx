# Benachrichtigungen, Bestelldruck und Lieferscheine

Damit können Sie Ablaufdaten und Chargennummern hinzufügen zu:

-   [Shopify-Benachrichtigungen](https://www.shopify.com/admin/settings/notifications) (gilt standardmäßig nicht für die Bestellbestätigung, da die E-Mail versendet wird, bevor die Charge zugewiesen ist)
-   [Order Printer](https://apps.shopify.com/order-printer) und [Shopify Order Printer](https://apps.shopify.com/shopify-order-printer)
-   [Order Printer Pro](https://apps.shopify.com/order-printer-pro)
-   [Multi-Label Barcodes App](https://apps.shopify.com/multi-label-barcodes)
-   Und weiteren!

Aktivieren Sie dazu zunächst die Bestellhinweise auf der <Link path="/settings#orders">Einstellungsseite</Link>, indem Sie die Option „Erstellen Sie einen Eintrag unter „Zusätzliche Details“ für die Integration von Drittanbieter-Apps“ auswählen. Generieren Sie anschließend nachfolgend das Code-Snippet für Ihre Integration.

## Code-Snippet

Das generierte Code-Snippet kann in die passende Liquid-Vorlage Ihrer Integration an der Stelle eingefügt werden, an der die Ablaufdaten angezeigt werden sollen. Dieses Snippet arbeitet **zusammen mit** der bestehenden Vorlage, um Ablaufdaten anzuzeigen; es ersetzt diese nicht.

Wenn Ihre Integration nicht aufgeführt ist und Sie Hilfe benötigen, wenden Sie sich bitte an den Support.

<SnippetGenerator />

### Falls Ihre Integration nicht aufgeführt ist

```liquid
{% comment %}
  Code for the Product Expiration Dates app to display a product's expiration date and related
  informtion in notifications, order printing, & packing slips.

  If you want to hide the expiration date until it's close to a particular number of days
  set the expires_window_days variable below to the number of desired days instead of blank.
  For example:

    {% assign expires_window_days = 30 %}

  For assistance contact support at help@screenstaring.com
{% endcomment %}

{% assign expires_window_days = blank %}

{% capture key %}Expiration Dates {{ line_item.sku }}{% endcapture %}
{% if attributes[key] != blank %}
    {% assign batches = attributes[key] | split: "|" %}
    {% for batch in batches %}
        {% assign batch_data = batch | split: "," %}
        {% assign expires_date = batch_data[0] %}
        {% assign expires_qty = batch_data[1] %}
        {% assign expires_batch = batch_data[2] %}

        {% assign now = "now" | date: "%s" %}
        {% assign seconds_in_a_day = 86400 %}
        {% assign expires_at = expires_date | date: "%s" | plus: seconds_in_day | minus: 1 %}
        {% assign diff = expires_at | minus: now | divided_by: seconds_in_a_day %}
        {% assign show_date = false %}

        {% if expires_window_days == blank  %}
          {% assign show_date = true %}
        {% elsif diff >= 0 and diff < expires_window_days %}
          {% assign show_date = true %}
        {% endif %}

        {% if show_date %}
          {% comment %}
            The date format can be adjust by changing the '%d/%m/%Y' portion below
            to the desired date format codes. See: https://shopify.dev/api/liquid/filters#date
            To use a tranlated date see: https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files
          {% endcomment %}
          MHD:
          {{ expires_date | date: "%d/%m/%Y" }}

          {% comment %}
            Remove the following if you do not want the quantity and batch name displayed
          {% endcomment %}
          ({{ expires_qty }})
          {% if expires_batch != blank %}
              {{ expires_batch }}
          {% endif %}
        {% endif %}
    {% endfor %}
{% endif %}
```

Möglicherweise müssen Sie die Variable `line_item` bzw. `line` an die in Ihrem vorhandenen Code verwendete Variable anpassen.

Das Datumsformat basiert auf dem [Liquid `date`-Filter](https://shopify.dev/api/liquid/filters#date). Es kann angepasst werden, indem der Teil `"%d/%m/%Y"` durch die gewünschten Formatcodes ersetzt wird. Eine Liste finden Sie in der Dokumentation des `date`-Filters. Um ein übersetztes Datum zu verwenden, geben Sie ein Datumsformat [aus den Sprachdateien Ihres Themes](https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files) an. Wenn beispielsweise das Format `month_day_year` existiert, können Sie:

```liquid
{{ expires_date | date: "%d/%m/%Y" }}
```

Im obigen Snippet wie folgt anpassen:

```liquid
{{ expires_date | date: format: "month_day_year" }}
```

## Technische Details

Für jede Bestellposition wird der Bestellung ein Attribut hinzugefügt. Das Attribut heißt `"Expiration Dates [ID]"`, wobei `[ID]` die SKU, der Barcode oder die Shopify-Varianten-ID der Bestellposition ist – je nach Konfiguration Ihres Shops. Wenn Sie SKUs verwenden, ist es stets die SKU; wenn Sie nur Barcodes nutzen, ist es der Barcode usw.

Der Wert des Attributs ist eine kommagetrennte Zeichenfolge mit dem zugewiesenen Ablaufdatum, der Menge und der Chargennummer:

```
2023-04-22,2,BATCH-NUMBER
```

Gibt es für eine Bestellposition mehrere Zuweisungen, werden diese durch einen senkrechten Strich (`|`) getrennt:

```
2023-04-22,2,BATCH-NUMBER-1|2023-12-25,1,BATCH-NUMBER-2
```
