# Ablaufende Bestandschargen automatisch entfernen

Das Entfernen von Bestandschargen basierend auf ihrem Ablaufdatum kann durch Auswählen der Option „Ablaufende Lagerbestände aus Shopify entfernen“ auf der <Link path="/settings#inventory">Registerkarte „Bestand“ der Einstellungsseite</Link> oder als Teil eines [Regelsatzes](/docs/product-expiration-dates/discounts#rulesets) über die Aktion „Bestandscharge entfernen“ erfolgen.
