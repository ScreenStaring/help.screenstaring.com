# Erfassung der Stückkosten einer Charge

Das Shopify-Feld „Kosten pro Artikel“ speichert nur einen Kostenwert pro Variante. Wenn dieser aktualisiert wird, geht die Unterscheidung zwischen Lieferungen verloren, die zu unterschiedlichen Preisen eingekauft wurden.
Mit der Product Expiration Dates App können Sie Kosten pro Charge eingeben, wodurch Benutzer die Kostenhistorie von Lieferungen präzise nachverfolgen können.

Sie können jeder Lieferung über das Feld „Stückkosten (Ch.)“ Werte zuweisen:

1. Rufen Sie die <Link path="/inventories/new">Seite für Bestandschargen</Link> auf
1. Klicken Sie auf der Registerkarte „Chargen“ auf das Zahnrad-Symbol:
<div><img src="/product-expiration-dates/images/inventory-batch-column-config.jpg" height="247" alt="Auswahl der Spalten für Bestandschargen" /></div>
1. Dadurch öffnet sich ein Menü mit zusätzlichen Feldern
1. Wählen Sie „Stückkosten (Ch.)“ (bzw. „Batch unit cost“)
1. Klicken Sie auf <kbd>Speichern</kbd>

Nun wird das Feld für die Stückkosten der Charge jedes Mal angezeigt, wenn Sie Chargen hinzufügen.

Sie können die Stückkosten der Charge auch auf der Startseite der Bestandschargen anzeigen lassen, indem Sie dieselben Schritte ausführen.
