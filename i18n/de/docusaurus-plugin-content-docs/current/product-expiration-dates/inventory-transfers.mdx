# Bestandsübertragungen

***Die Unterstützung von Bestandsübertragungen ist nur im <Link path="/charges/recurring/new">Premium- und Platinum-Tarif</Link> verfügbar***

So aktivieren Sie die Unterstützung für [Shopify-Bestandsübertragungen](https://help.shopify.com/de/manual/products/inventory/inventory-transfers):

-   Rufen Sie die <Link path="/settings#inventory">Registerkarte „Bestand“ der Einstellungsseite</Link> auf
-   Aktivieren Sie die Option „Bestandschargen bei Shopify-Bestandsübertragungen verschieben“
-   Klicken Sie auf „Aktualisierung“

Wenn nun in Shopify eine Bestandsübertragung stattfindet, werden Bestandschargen für die übertragene Menge vom Ursprungsort zum Zielort verschoben. Mengen werden dabei beginnend mit der am frühesten ablaufenden Bestandscharge bewegt. Sollten Sie einen anderen Ablauf benötigen, wenden Sie sich bitte an den Support.
