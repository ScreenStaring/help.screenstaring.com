# Attribution de l'emplacement des lots d'inventaire aux commandes

L'application Product Expiration Dates vous permet de configurer le moment où les lots d'inventaire sont attribués à une commande : soit lorsque la commande est passée, soit lorsqu'une ligne de commande est traitée. Voir [Ajouter des données d'expiration aux produits](/docs/product-expiration-dates/adding-expiration-data).

Par défaut, le lot d'inventaire d'un produit qui expire le plus tôt, tous emplacements confondus, est attribué à la ligne de commande (stratégie de gestion FEFO : premier expiré, premier sorti). Si la commande entrante a un emplacement attribué (généralement les [commandes Shopify Point of Sale (POS)](/docs/product-expiration-dates/pos-integration)), cet emplacement sera utilisé.

Vous pouvez changer votre méthode de gestion de l'inventaire pour le premier entré, premier sorti (FIFO) dans <Link path="/settings#inventory">l'onglet Inventaire de la page des paramètres</Link>.

## Règles de routage des commandes Shopify

***La prise en charge des règles de routage des commandes Shopify n'est disponible qu'avec le <Link path="/charges/recurring/new">forfait Pro</Link>***

Pour attribuer un lot d'inventaire provenant d'un emplacement déterminé par les règles de routage des commandes Shopify, sélectionnez « Affecter les lots d'inventaire en fonction du routage des commandes Shopify » dans <Link path="/settings#inventory">l'onglet Inventaire de la page des paramètres</Link>. Le routage des commandes Shopify peut être configuré dans <ShopifyLink href={(shopify) => shopify.toString() + '/settings/shipping/order_routing'}>l'interface administrateur Shopify</ShopifyLink>.

## Attribuer les lots d'inventaire d'un emplacement spécifique {/* #order-placed-allocation-location */}

**Ne définissez pas ceci si vous utilisez des [emplacements de traitement priorisés](https://help.shopify.com/fr/manual/locations/setting-up-your-location-fulfillments#set-locations-for-order-fulfillment-priority).**

Si vous utilisez « La commande est passée » pour le paramètre [« Affecter les lots d'inventaire lorsque »](/docs/product-expiration-dates/adding-expiration-data) d'un produit et que vous avez plusieurs emplacements dans Shopify **mais que vous ne traitez les commandes qu'à partir d'un seul**, vous devez <Link path="/settings#inventory">définir le champ « Affecter les lots d'inventaire depuis cet emplacement »</Link> pour qu'il corresponde à votre emplacement par défaut dans Shopify. Lorsque ce champ est défini et qu'une commande est passée sans emplacement, l'application Product Expiration Dates n'attribuera que la date d'expiration la plus proche provenant de cet emplacement. Si ce champ n'est pas défini, l'application attribuera la date d'expiration la plus proche parmi tous les emplacements.

Notez que Shopify ne partage pas l'emplacement par défaut d'une boutique avec les applications tierces, il doit donc être défini explicitement.
