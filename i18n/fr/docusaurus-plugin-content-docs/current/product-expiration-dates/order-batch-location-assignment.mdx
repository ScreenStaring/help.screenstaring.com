# Attribution de l'emplacement des lots d'inventaire aux commandes

L'application Product Expiration Dates vous permet de configurer le moment où les lots d'inventaire sont attribués à une commande : soit lorsque la commande est passée, soit lorsqu'une ligne de commande est traitée. Voir [Ajouter des données d'expiration aux produits](/docs/product-expiration-dates/adding-expiration-data).

Par défaut, le lot d'inventaire d'un produit qui expire le plus tôt, tous emplacements confondus, est attribué à la ligne de commande (stratégie de gestion FEFO : First Expired, First Out). Si la commande entrante a un emplacement attribué (généralement les [commandes Shopify Point of Sale (POS)](/docs/product-expiration-dates/pos-integration)), cet emplacement sera utilisé. Vous pouvez changer votre stratégie de gestion pour First In, First Out (FIFO) dans <Link path="/settings#inventory">l'onglet Inventory de la page des paramètres</Link>.

## Règles de routage des commandes Shopify

***La prise en charge des règles de routage des commandes Shopify n'est disponible qu'avec le <Link path="/charges/recurring/new">forfait Pro</Link>***

Pour attribuer un lot d'inventaire provenant d'un emplacement déterminé par les règles de routage des commandes Shopify, sélectionnez "Assign inventory batches based on Shopify Order Routing" dans <Link path="/settings#inventory">l'onglet Inventory de la page des paramètres</Link>. Le routage des commandes Shopify peut être configuré dans l'admin Shopify ici

## Attribuer les lots d'inventaire d'un emplacement spécifique {/* #order-placed-allocation-location */}

**Ne définissez pas ceci si vous utilisez des [emplacements de traitement priorisés](https://help.shopify.com/en/manual/locations/setting-up-your-location-fulfillments#set-locations-for-order-fulfillment-priority).**

Si vous utilisez "order placed" pour le paramètre ["Assign inventory batches when"](/docs/product-expiration-dates/adding-expiration-data) d'un produit et que vous avez plusieurs emplacements dans Shopify **mais que vous ne traitez les commandes qu'à partir d'un seul**, vous devez <Link path="/settings#inventory">définir "Assign inventory batches from this location"</Link> pour qu'il corresponde à votre emplacement par défaut dans Shopify (Shopify ne le partage pas avec les applications tierces, il doit donc être défini explicitement). Lorsque ceci est défini et qu'une commande est passée sans emplacement, l'application Product Expiration Dates n'attribuera que la date d'expiration la plus proche provenant de cet emplacement. Si ce n'est pas défini, l'application attribuera la date d'expiration la plus proche parmi tous les emplacements.
