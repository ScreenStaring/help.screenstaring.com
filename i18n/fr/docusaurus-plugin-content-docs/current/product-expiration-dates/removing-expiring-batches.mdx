# Supprimer automatiquement les lots d'inventaire arrivant à expiration

La suppression des lots d'inventaire selon leur date d'expiration peut se faire en sélectionnant "Remove expiring inventory from Shopify" dans <Link path="/settings#inventory">l'onglet Inventory de la page des paramètres</Link> ou dans le cadre d'un [Ruleset](/docs/product-expiration-dates/discounts#rulesets) avec une action Remove Inventor Batch.
