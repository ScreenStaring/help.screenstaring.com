# Supprimer automatiquement les lots d'inventaire arrivant à expiration

La suppression des lots d'inventaire selon leur date d'expiration peut se faire en sélectionnant « Supprimer de Shopify l'inventaire arrivant à expiration » dans <Link path="/settings#inventory">l'onglet Inventaire de la page des paramètres</Link> ou dans le cadre d'un [ensemble de règles](/docs/product-expiration-dates/discounts#rulesets) avec une action Supprimer le lot d'inventaire.
