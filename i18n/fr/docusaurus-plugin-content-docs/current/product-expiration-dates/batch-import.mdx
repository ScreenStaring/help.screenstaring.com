# Importer des données de péremption en masse

Vous pouvez importer plusieurs dates de péremption et les quantités correspondantes à l'aide de notre fichier CSV d'importation des lots de stock. Un modèle est disponible [ici](/product-expiration-dates/images/product-expiration-dates-import-template.csv).

Les colonnes « SKU », « Expiration Date », « Quantity » et « Location Name » sont obligatoires. **Les dates de péremption doivent être au format `YYYY-MM-DD` (année-mois-jour).**

Pour utiliser le code-barres à la place du SKU, sélectionnez l'option « Identify rows by Barcode » sur la page d'importation des lots de stock.

Pour en savoir plus sur la colonne « Allocate Quantities to Orders When », consultez la documentation [Ajouter les données de péremption aux produits](/docs/product-expiration-dates/adding-expiration-data).

Le fichier CSV doit être encodé en UTF-8 et utiliser la virgule (`,`) comme séparateur de champs.

Une fois le fichier prêt, importez-le depuis <Link path="/import">la page d'importation</Link>.
