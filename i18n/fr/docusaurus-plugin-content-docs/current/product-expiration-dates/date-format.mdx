# Modifier le format de date et d'heure

Le format de date affiché dans l'application est déterminé par votre paramètre régional. Celui-ci peut être modifié dans <Link path="/settings#general">l'onglet general de la page des paramètres</Link>. Par défaut, nous utilisons le paramètre régional fourni par Shopify. Modifier le paramètre régional n'affecte pas les dates d'expiration des lots d'inventaire. Cela change uniquement le format utilisé pour les afficher.

Le format de date affiché sur votre site peut être configuré lors de [l'ajout de données d'expiration à votre site](/docs/product-expiration-dates/shopify-pages).
