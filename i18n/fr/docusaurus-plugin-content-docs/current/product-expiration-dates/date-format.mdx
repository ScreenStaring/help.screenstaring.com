# Modifier les formats de date et d'heure

Le format des dates affichées dans l'application dépend de votre paramètre régional. Vous pouvez modifier ce paramètre dans <Link path="/settings#general">l'onglet General de la page des paramètres</Link>.

Par défaut, l'application utilise le paramètre régional fourni par Shopify. La modification de ce paramètre ne change pas les dates de péremption enregistrées pour les lots de stock. Elle modifie uniquement le format dans lequel ces dates sont affichées.

Vous pouvez configurer le format des dates affichées sur votre boutique en ligne lors de [l'ajout des données de péremption à votre boutique](/docs/product-expiration-dates/shopify-pages).
