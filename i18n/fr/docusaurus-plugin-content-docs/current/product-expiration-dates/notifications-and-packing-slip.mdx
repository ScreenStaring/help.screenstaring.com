# Notifications, impression de commandes et bordereaux d'expédition

Cela vous permet d'ajouter les dates d'expiration et les numéros de lot à :

-   [Notifications Shopify](https://www.shopify.com/admin/settings/notifications) (par défaut, ne s'applique pas à la confirmation de commande, car l'e-mail est envoyé avant l'attribution du lot)
-   [Order Printer](https://apps.shopify.com/order-printer) et [Shopify Order Printer](https://apps.shopify.com/shopify-order-printer)
-   [Order Printer Pro](https://apps.shopify.com/order-printer-pro)
-   [Application Multi-Label Barcodes](https://apps.shopify.com/multi-label-barcodes)
-   Et plus encore !

Pour commencer, vous devez activer les notes de commande <Link path="/settings#orders">depuis la page des paramètres</Link> en sélectionnant "Create an order 'additional details' entry for 3rd-party app integration". Une fois activé, générez un extrait de code ci-dessous pour votre intégration.

## Extrait de code

L'extrait de code obtenu peut être ajouté au modèle Liquid approprié pour votre intégration, à l'endroit où vous voulez que les données d'expiration soient affichées. Cet extrait fonctionne **avec** le modèle existant pour afficher les données d'expiration. Il n'est pas destiné à le remplacer.

Si vous ne voyez pas votre intégration dans la liste et avez besoin d'aide, veuillez contacter le support.

```liquid
{% comment %}
  Code for the Product Expiration Dates app to display a product's expiration date and related
  informtion in notifications, order printing, & packing slips.

  If you want to hide the expiration date until it's close to a particular number of days
  set the expires_window_days variable below to the number of desired days instead of blank.
  For example:

    {% assign expires_window_days = 30 %}

  For assistance contact support at help@screenstaring.com
{% endcomment %}

{% assign expires_window_days = blank %}

{% capture key %}Expiration Dates {{ line_item.sku }}{% endcapture %}
{% if attributes[key] != blank %}
    {% assign batches = attributes[key] | split: "|" %}
    {% for batch in batches %}
        {% assign batch_data = batch | split: "," %}
        {% assign expires_date = batch_data[0] %}
        {% assign expires_qty = batch_data[1] %}
        {% assign expires_batch = batch_data[2] %}

        {% assign now = "now" | date: "%s" %}
        {% assign seconds_in_a_day = 86400 %}
        {% assign expires_at = expires_date | date: "%s" | plus: seconds_in_day | minus: 1 %}
        {% assign diff = expires_at | minus: now | divided_by: seconds_in_a_day %}
        {% assign show_date = false %}

        {% if expires_window_days == blank  %}
          {% assign show_date = true %}
        {% elsif diff >= 0 and diff < expires_window_days %}
          {% assign show_date = true %}
        {% endif %}

        {% if show_date %}
          {% comment %}
            The date format can be adjust by changing the '%d/%m/%Y' portion below
            to the desired date format codes. See: https://shopify.dev/api/liquid/filters#date
            To use a tranlated date see: https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files
          {% endcomment %}
          Expires:
          {{ expires_date | date: "%d/%m/%Y" }}

          {% comment %}
            Remove the following if you do not want the quantity and batch name displayed
          {% endcomment %}
          ({{ expires_qty }})
          {% if expires_batch != blank %}
              {{ expires_batch }}
          {% endif %}
        {% endif %}
    {% endfor %}
{% endif %}
```

Vous devrez peut-être remplacer la variable `line_item` ou `line` pour qu'elle corresponde à celle utilisée dans votre code existant.

Le format de date est basé sur le [filtre `date` de Liquid](https://shopify.dev/api/liquid/filters#date). Il peut être ajusté en modifiant la portion `"%d/%m/%Y"` pour utiliser les codes de format de date souhaités. Consultez la documentation du filtre `date` pour en obtenir la liste. Pour utiliser une date traduite, spécifiez un format de date [provenant des fichiers de paramètres régionaux de votre thème](https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files). Par exemple, si le format `month_day_year` existait (c'est possible), vous pouvez remplacer :

```liquid
{{ expires_date | date: "%d/%m/%Y" }}
```

Dans l'extrait ci-dessus par :

```liquid
{{ expires_date | date: format: "month_day_year" }}
```

## Détails techniques

Un attribut sera ajouté à la commande pour chaque ligne de commande. L'attribut sera nommé `"Expiration Dates [ID]"` où `[ID]` est le SKU, le code-barres ou l'ID de variante Shopify de la ligne de commande. Ce qui est utilisé dépend de la configuration de votre boutique. Si vous utilisez des SKU, ce sera toujours le SKU. Si vous n'utilisez qu'un code-barres, ce sera le code-barres, etc...

La valeur de l'attribut est une chaîne séparée par des virgules contenant la date d'expiration attribuée, la quantité et le numéro de lot :

```
2023-04-22,2,BATCH-NUMBER
```

S'il y a plusieurs attributions pour une ligne de commande, chaque attribution sera séparée par le caractère barre verticale (`|`) :

```
2023-04-22,2,BATCH-NUMBER-1|2023-12-25,1,BATCH-NUMBER-2
```
