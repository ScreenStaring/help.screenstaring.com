# Partager l'inventaire entre plusieurs boutiques

Si votre inventaire alimente plusieurs boutiques, ces boutiques peuvent être liées. Le fait de lier des boutiques permet de partager un même ensemble de données d'expiration entre plusieurs boutiques.

Pour lier des boutiques, vous devez :

-   Installer l'application dans chaque boutique (après la période d'essai, toutes les boutiques doivent avoir un abonnement actif)
-   Utiliser les mêmes SKU de produit dans chaque boutique (le code-barres peut être utilisé à la place, si vous préférez)
-   Si vous utilisez des emplacements, utiliser les mêmes noms d'emplacement dans chaque boutique
-   [Contacter le support](https://screenstaring.com/#contact) pour créer le(s) lien(s)
