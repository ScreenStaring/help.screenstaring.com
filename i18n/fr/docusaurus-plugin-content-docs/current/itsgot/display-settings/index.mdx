# Modifier le design d'une étiquette

Les paramètres s'appliquent à 2 niveaux :

1. Les valeurs par défaut du site, qui s'appliquent à toutes les nouvelles étiquettes
2. Les valeurs propres à chaque étiquette

Les valeurs par défaut du site peuvent être configurées sur la <Link path="/settings/edit#label-display-settings">page des paramètres de votre compte</Link>.

Les valeurs propres à une étiquette peuvent être définies lors de la création ou de la modification d'une étiquette, dans la <Link path="/nutrition_facts/new#label-display-settings">section des paramètres d'affichage de l'étiquette</Link>.
Ces paramètres sont répartis en :

1. **Général** - Paramètres de base qui s'appliquent à tout le contenu de l'étiquette. Largeur, taille de police, etc.
2. **Panneau nutritionnel** - Paramètres qui s'appliquent spécifiquement au panneau. Taille, couleur et épaisseur de bordure, etc.
3. **CSS personnalisé** - CSS propre au site à inclure dans toutes les nouvelles étiquettes

Les couleurs et le design des champs de texte comme les ingrédients et les avertissements peuvent être modifiés directement dans le champ concerné.

Les paramètres peuvent aussi être configurés ligne par ligne dans le panneau nutritionnel. Cela comprend par exemple la modification de l'indentation d'un nutriment, la mise en gras de son texte,
et l'ajout de liens vers d'autres produits ou pages de votre site. Pour configurer un paramètre pour une ligne, cliquez sur le lien *Paramètres d'affichage* après
avoir sélectionné ou saisi une valeur :
