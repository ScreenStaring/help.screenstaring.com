# Ordre des nutriments

Les nutriments peuvent être listés dans n'importe quel ordre au lieu de l'ordre par défaut du format de l'étiquette :

1. Trouvez le produit souhaité et cliquez sur le bouton « Modifier »
1. Dans l'éditeur d'étiquette, accédez à la section « Nutriments »
1. Cochez « Utiliser un ordre personnalisé »
1. Faites glisser la poignée (⋮⋮) d'une ligne pour la déplacer vers le haut ou vers le bas
   {/* Image temporairement désactivée : /itsgot/shopify/images/label-custom-nutrient-order.jpg non disponible
   <div>
     <img src="/itsgot/shopify/images/label-custom-nutrient-order.jpg" width="700" alt="Personnaliser l'ordre des nutriments d'une étiquette" />
   </div>
   */}
1. Cliquez sur <kbd>Mettre à jour</kbd>

Cet ordre n'est utilisé que par l'étiquette. Il ne modifie pas l'ordre dans lequel les nutriments apparaissent ailleurs.

:::info
L'ordre personnalisé n'est pas disponible pour le format d'étiquette « Tabulaire ».
:::
