# Intégration de l'API


**L'intégration de l'API n'est disponible qu'avec le <Link path="/app/plans">forfait Premium</Link>.**

Les requêtes API sont authentifiées à l'aide de votre clé API.
Incluez votre clé API dans l'en-tête `X-API-Key` de chaque requête.
Contactez le support pour obtenir la vôtre.

## URL de base

Tous les points de terminaison de l'API sont relatifs à : `https://itsgot.com`

## Pagination

Pour les points de terminaison qui prennent en charge la pagination, les URL de la page suivante et de la page précédente se trouvent dans l'en-tête HTTP `Link`.

## Récupérer les produits

### GET /api/products

**Paramètres de requête :**

- `sku` - Le SKU de la variante (facultatif)
- `barcode` - Le code-barres de la variante (facultatif)
- `external_product_id` - ID du produit Shopify (facultatif)
- `external_variant_id` - ID du produit Shopify (facultatif)
- `page` - Page à récupérer (facultatif)
- `per_page` - Nombre de produits renvoyés par page, doit être l'une des valeurs `10`, `25`, `50`, `100` (facultatif, 10 par défaut)

**Exemple avec curl :**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products?sku=JARFOOD'
```

## Exporter une étiquette dans un format donné

### GET /api/products/PRODUCT_ID/labels/LABEL_ID/export.FORMAT

**Paramètres obligatoires :**

- `PRODUCT_ID` - ID du produit dont vous souhaitez exporter l'étiquette
- `LABEL_ID` - ID de l'étiquette que vous souhaitez exporter
- `FORMAT` - Format d'exportation. L'un de `png`, `jpg`, `pdf` ou `html`

**Paramètres de requête facultatifs :**

- `width` - Image uniquement. Exporte l'étiquette à la largeur donnée. La valeur par défaut est la largeur de l'étiquette x 2.
- `height` - Image uniquement. Exporte l'étiquette à la hauteur donnée. Par défaut, le rapport hauteur/largeur est conservé et la hauteur est calculée à partir de la largeur donnée.
- `background_color` - Image uniquement. Couleur d'arrière-plan à utiliser si l'étiquette est redimensionnée et ne conserve plus son rapport hauteur/largeur

**Exemple avec curl :**

```bash
curl -H 'X-API-Key: ***' 'https://itsgot.com/api/products/123/labels/789/export.jpg' > product.jpg
```
