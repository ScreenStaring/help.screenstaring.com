# Désinstaller l'application


Avant de désinstaller l'application, les étiquettes de produits existantes doivent être supprimées.
Cela comprend :

1. Les étiquettes ajoutées automatiquement aux descriptions de vos produits
2. Les étiquettes ajoutées manuellement via le code d'intégration

## Étiquettes ajoutées automatiquement aux descriptions de vos produits

Ces étiquettes peuvent être supprimées en supprimant toutes vos étiquettes. Pour ce faire :

1. Consultez la page <Link path="/nutrition_facts">Mes étiquettes</Link>
2. Pour chaque étiquette ajoutée automatiquement, cliquez sur son bouton <kbd>Supprimer</kbd> :

   <img src="/itsgot/shopify/images/nf-index-delete-product.jpg" alt="Supprimer l'étiquette d'un produit" />

Si vous avez besoin d'aide, <SupportEmail subject="Remove Product Labels">contactez notre équipe de support</SupportEmail>.

## Étiquettes ajoutées manuellement via le code d'intégration

Le code d'intégration que vous avez ajouté manuellement à votre site ne sera pas supprimé automatiquement. Vous devez le faire vous-même.
Si vous avez besoin d'aide, <SupportEmail subject="Remove Product Labels">contactez notre équipe de support</SupportEmail>.
