title: Guide de l'utilisateur d'It's Got
sidebar_position: 0
description: Comment utiliser l'application It's Got Nutrition Facts pour Shopify.
---

[It's Got](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link) gère les données nutritionnelles des produits et permet d'ajouter des panneaux d'information sur les suppléments, les médicaments, les animaux de compagnie et la nutrition à votre site.
Les étiquettes peuvent être générées dans des formats reconnus pour plusieurs pays et langues.
