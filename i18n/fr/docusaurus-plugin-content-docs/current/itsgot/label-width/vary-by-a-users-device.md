# Variable selon l'appareil de l'utilisateur

Différentes étiquettes peuvent être affichées selon l'appareil utilisé par le visiteur. C'est utile lorsque le texte d'une étiquette serait trop
petit pour être lu sur une tablette ou un téléphone, ou lorsque l'écran d'un tel appareil ne peut pas contenir toute la largeur d'une étiquette.

Chaque étiquette possède un *Appareil cible*. Pour le définir :

1. Sur la page du produit, accédez à sa page Étiquettes
1. Créez une nouvelle étiquette ou modifiez-en une existante
1. Accédez à l'onglet « Affichage »
1. Sélectionnez un appareil dans le menu « Appareil cible » :

   - **Ordinateur de bureau** - affichée sur les écrans de 992 pixels et plus
   - **Tablette** - affichée sur les écrans entre 577 et 991 pixels
   - **Mobile** - affichée sur les écrans jusqu'à 576 pixels
   - **Personnalisé** - affichée sur les écrans dont la largeur se situe dans la plage définie par les champs « Largeur d'écran minimale » et « Largeur d'écran maximale »
   - **Tout** (valeur par défaut) - affichée sur tous les écrans, quelle que soit leur taille

1. Cliquez sur <kbd>Mettre à jour</kbd>

Pour afficher une étiquette différente pour chaque appareil, par exemple une étiquette pour les ordinateurs de bureau et une pour les téléphones, créez une étiquette pour chaque
appareil et définissez l'*Appareil cible* de chacune. Seules les étiquettes adaptées à l'écran du visiteur sont affichées; les autres sont ignorées.
L'appareil cible d'une étiquette est indiqué dans la colonne « Appareil cible » de la page Étiquettes d'un produit.

:::info
C'est la largeur de l'écran de l'appareil qui est utilisée, pas la largeur de la fenêtre du navigateur. Cela signifie qu'un visiteur verra toujours la même étiquette sur un
appareil donné, même s'il redimensionne la fenêtre de son navigateur.
:::
