# Définir la largeur d'une étiquette

La largeur d'une étiquette peut être :

- Une valeur fixe en pixels
- Un pourcentage de la taille de son élément HTML parent
- Variable selon l'appareil de l'utilisateur, par exemple tablette ou ordinateur de bureau

Les largeurs fixe et en pourcentage peuvent être définies via le champ « Largeur » d'une étiquette, situé dans la section Général des paramètres d'affichage de l'étiquette.
Le champ de largeur est composé de la valeur de la largeur et de son unité :

<div>
    <img src="/itsgot/images/label-width-value-and-unit-field.jpg" width="500" alt="Utiliser le champ Largeur de l'étiquette" />
</div>

L'unité peut être soit des pixels (`px`), soit un pourcentage (`%`).

Une largeur par défaut peut être définie sur la <Link path="/settings/edit#label-display-settings">page des paramètres de votre compte</Link>.

Chaque option est décrite dans les pages suivantes :

- [Valeur fixe en pixels](fixed-pixel-value.md)
- [Pourcentage de la taille de son élément HTML parent](percentage-of-its-parent-html-elements-size.md)
- [Variable selon l'appareil de l'utilisateur](vary-by-a-users-device.md)
