# Ajouter des étiquettes nutritionnelles à votre site

Il existe plusieurs façons d'ajouter des étiquettes nutritionnelles à votre site.

## Shopify

Si vous utilisez Shopify, installez notre [application Shopify Nutrition Facts](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

La majorité des utilisateurs de Shopify devraient utiliser l'éditeur de thème Shopify pour ajouter les étiquettes nutritionnelles.

- [Éditeur de thème Shopify](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Bouton Ajouter à la description du produit](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Code d'intégration de l'étiquette

Le code d'intégration peut être utilisé pour faire apparaître l'étiquette d'un produit n'importe où.

- [Code d'intégration de l'étiquette](/docs/itsgot/adding-labels/embed-code)
Vous pouvez aussi utiliser la [Combine API](/docs/itsgot/combine-api).
