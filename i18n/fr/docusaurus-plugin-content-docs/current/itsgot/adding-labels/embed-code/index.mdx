# Code d'intégration de l'étiquette

Le code d'intégration de l'étiquette est un extrait HTML qui vous permet d'ajouter une étiquette à n'importe quelle page de votre site.

Pour ajouter une étiquette à l'aide du code d'intégration :

1. <Link path="/nutrition_facts/new">Créez une étiquette de produit</Link>.
   Si le produit existe déjà, retrouvez-le sur la page <Link path="/nutrition_facts">Mes étiquettes</Link> et cliquez sur le nom du produit.

2. Cliquez sur le bouton <kbd>Copier le code</kbd> pour copier le code d'intégration dans le presse-papiers. Cela
   vous permettra de coller le code dans votre site lors d'une étape ultérieure :

   <img src="/itsgot/shopify/images/nf-edit-embed-code.jpg" alt="Copier le code d'intégration" />

3. Sélectionnez l'endroit où vous souhaitez ajouter votre extrait. La capture d'écran ci-dessous utilise les articles de blog et les pages,
   mais ces instructions s'appliquent aussi aux collections et aux produits :

   <img src="/itsgot/shopify/images/shopify-select-page.jpg" alt="Sélectionner une page dans l'admin Shopify" />

4. Sélectionnez un article de blog (ou une page, une collection ou un produit) existant auquel vous souhaitez ajouter l'étiquette.
   Si l'article de blog n'existe pas, créez-en un nouveau :

   <img src="/itsgot/shopify/images/shopify-select-entry.jpg" alt="Sélectionner une entrée de blog" />

5. Trouvez dans la zone de contenu l'endroit où vous souhaitez afficher l'étiquette de votre produit. Comme vous allez passer
   en mode HTML pour insérer le code d'intégration, il est judicieux d'insérer un texte repère que vous remplacerez ensuite.
   Dans ce cas, nous avons ajouté le texte *REPLACE ME* :

   <img src="/itsgot/shopify/images/shopify-blog-replace-me.jpg" alt="Insérer le texte repère REPLACE ME" />

6. Cliquez sur le bouton pour modifier en mode HTML :

   <img src="/itsgot/shopify/images/shopify-blog-select-html.jpg" alt="Sélectionner le mode HTML" />

7. La zone de contenu affiche maintenant du code HTML :

   <img src="/itsgot/shopify/images/shopify-blog-edit-html.jpg" alt="Zone de contenu en mode HTML" />

8. Supprimez le texte *REPLACE ME* et collez le code d'intégration copié à l'étape 2 :

   <img src="/itsgot/shopify/images/shopify-blog-insert-snippet.jpg" alt="Coller le code d'intégration" />

9. Pour terminer, cliquez sur le bouton <kbd>Enregistrer</kbd> :

   <img src="/itsgot/shopify/images/shopify-blog-save-snippet.jpg" alt="Enregistrer l'article de blog" />

L'étiquette du produit fait maintenant partie de l'article de blog.
