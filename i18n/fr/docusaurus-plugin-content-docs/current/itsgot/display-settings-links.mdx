# Créer des liens vers des pages web à partir des nutriments d'une étiquette


Si votre abonnement comprend les <Link path="/app/plans">fonctionnalités du forfait Premium</Link>, vous pouvez transformer un nutriment ou un ingrédient diététique d'une étiquette en lien vers la page web de votre choix.

Pour créer un lien :

1. <Link path="/nutrition_facts/new">Créez</Link> une étiquette de produit ou modifiez-en une existante
2. Dans les sections <Link path="/nutrition_facts/new#nutrients">Nutriments</Link> ou <Link path="/nutrition_facts/new?label_format=supplement_vertical#dietary-ingredients">Ingrédients diététiques</Link>, ajoutez ou modifiez une valeur
3. Une fois une valeur saisie, un lien *Paramètres d'affichage* apparaîtra :

   <img src="/itsgot/images/product-labels-new-display-settings-link.png" width="500" alt="Lien des paramètres d'affichage" />

4. Cliquez sur le lien pour ouvrir la boîte de dialogue *Paramètres d'affichage*. Dans le champ URL de la section *Lien*, saisissez la page vers laquelle créer le lien.
5. Par défaut, le lien s'ouvrira dans la même page. Vous pouvez le faire ouvrir dans une nouvelle fenêtre/un nouvel onglet en sélectionnant *Ouvrir dans une nouvelle fenêtre/un nouvel onglet*.
6. Cliquez sur <kbd>Enregistrer</kbd> ou <kbd>Mettre à jour</kbd> pour enregistrer
7. Désormais, lorsque l'étiquette est affichée sur votre site, un lien apparaîtra du nutriment ou de l'ingrédient diététique vers l'URL donnée

   <img src="/itsgot/images/product-labels-nutrient-linked.png" width="500" alt="Nutriment lié sur l'étiquette" />

Pour modifier la couleur du lien, voir la section [Modifier les couleurs et le design d'une étiquette](/docs/itsgot/display-settings).
