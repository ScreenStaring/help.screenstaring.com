# Traduire le texte des étiquettes


Le texte d'une étiquette peut être modifié en créant une <Link path="/app/translations">traduction</Link>.
Les traductions permettent de modifier tout le texte d'une étiquette. Elles ne servent pas uniquement à traduire d'une langue à une autre.

L'utilisation des traductions nécessite de [définir la locale de l'étiquette](/docs/itsgot/multi-language#multi-language-label-locale).
Une fois la locale définie, des traductions peuvent être créées pour celle-ci : elles correspondent au texte source et le remplacent par le texte défini par l'utilisateur.

La traduction de blocs de texte tels que les ingrédients et les avertissements se fait sur la page de modification de l'étiquette, dans la section *Traductions*.
Voir [Traduire les ingrédients et autres blocs de texte](/docs/itsgot/multi-language#multi-language-label-translations).
