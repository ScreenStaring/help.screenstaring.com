# 無効化された商品

Shopifyで商品が削除された場合でも、その商品に在庫バッチが割り当てられた注文が存在する場合、アプリ内ではその商品が「無効」状態になります。これにより、過去の在庫バッチ割り当て履歴を保持しつつ、今後の注文で処理されるのを防ぐことができます。Shopifyで商品が削除され、かつ在庫バッチが一切割り当てられていない場合は、アプリからも削除されます。

## 複数ストア間での在庫共有

複数ストア間での在庫共有では、在庫バッチの割り当てに一意のSKUまたはバーコードが使用されます。アプリ内に重複した商品が存在する場合、不要な商品を無効化して処理対象外にすることができます。無効化するには、アプリ内の商品ページにある<kbd>「無効化」</kbd>ボタンをクリックします。
