# バーコードスキャナーによる入力

商品名、SKU、またはバーコードを手入力して検索する代わりに、商品のバーコードをスキャンすることで、在庫受入（入庫）や在庫バッチの割り当て作業の効率を大幅に向上させることができます。
利用を開始するには、[Barcode Scannerアプリ](https://apps.shopify.com/barcode-scanner-1?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link)をインストールしてください。
Barcode Scannerアプリは、[Shopifyモバイルアプリ](https://www.shopify.com/mobile)内から使用する必要があります。
