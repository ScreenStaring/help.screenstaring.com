# 複数ストア間での在庫共有

保有する在庫を複数のストアに供給している場合、それらのストアを連携させることができます。ストア同士を連携させることで、単一の有効期限データを複数のストア間で共有できるようになります。

ストアを連携させるための要件：

-   各ストアにアプリをインストールすること（トライアル期間終了後は、すべてのストアで有効なサブスクリプションが必要です）
-   各ストアで同一の商品SKUを使用すること（ご希望の場合は、代わりにバーコードを使用することも可能です）
-   ロケーションを使用する場合は、各ストアで同一のロケーション名を使用すること
-   連携を設定するために[サポートにお問い合わせ](https://screenstaring.com/#contact)すること
