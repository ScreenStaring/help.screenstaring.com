# 日付・時刻の表示形式の変更

アプリ内で表示される日付の形式は、ロケールによって決定されます。ロケールは設定ページの<Link path="/settings#general">「一般」タブ</Link>で変更できます。デフォルトでは、Shopifyから提供されるロケールが使用されます。ロケールを変更しても、在庫バッチの有効期限そのものには影響しません。表示に使用される形式のみが変更されます。

サイト上に表示される日付形式の設定については、[サイトへの有効期限データの追加](/docs/product-expiration-dates/shopify-pages)をご覧ください。
