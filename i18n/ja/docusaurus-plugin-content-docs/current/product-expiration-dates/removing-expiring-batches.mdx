# 期限切れ間近の在庫バッチの自動削除

有効期限に基づいて在庫バッチを自動削除するには、<Link path="/settings#inventory">設定ページの「在庫」タブ</Link>から「Shopifyから有効期限が切れる在庫を削除する」を選択するか、[ルールセット](/docs/product-expiration-dates/discounts#rulesets)の一部として「在庫バッチを削除」アクションを設定します。
