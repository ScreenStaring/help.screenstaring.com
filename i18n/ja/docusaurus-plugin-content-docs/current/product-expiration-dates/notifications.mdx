# メール通知

商品の有効期限を迎える前に、メール通知を送信するように設定できます。アプリに登録されたすべての有効期限に適用される全体共通の設定のほか、商品のコレクション別や商品タイプ別に設定することも可能です。

## 有効化の手順

1.  アプリの設定画面で<Link path="/settings#email_notifications">メール通知</Link>に移動します
2.  「通知の送信先」項目に、通知を受信したいメールアドレスを入力します。複数のメールアドレスはカンマで区切ることができます。
3.  「商品の有効期限の何日前に通知を受け取りますか？」項目に、有効期限の何日前に通知を受け取りたいかの日数を入力します。  
    例えば、商品の有効期限が1月15日で「10」と入力した場合、その商品に関する通知が1月5日から送信されるようになります。
4.  <kbd>「更新」</kbd>ボタンをクリックして設定を保存します

通知は1日1回送信されます。有効期限の対象期間内に該当する商品がない場合、通知は送信されません。

商品のコレクションや商品タイプに基づいて通知を受け取りたい場合は、「商品の有効期限の何日前に通知を受け取りますか？」に値を入力せず、「コレクション別」または「商品タイプ別」セクションで該当するコレクションや商品タイプごとに日数を追加してください。これらの項目には、アプリに登録されている商品の値のみが表示されます。

## 無効化の手順

1.  アプリの設定画面で<Link path="/settings#email_notifications">メール通知</Link>に移動します
2.  「商品の有効期限の何日前に通知を受け取りますか？」項目の値を空にします。
3.  コレクション別または商品タイプ別の通知設定がある場合は、各通知設定の横にある赤い <kbd>「X」</kbd> ボタンを押して削除します
4.  <kbd>「更新」</kbd>ボタンをクリックして設定を保存します

これで通知は送信されなくなります。
