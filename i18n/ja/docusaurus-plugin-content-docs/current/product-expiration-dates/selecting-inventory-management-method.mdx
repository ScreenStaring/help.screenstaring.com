# 在庫管理方法の選択

在庫管理方法は、注文に在庫バッチをどのように割り当てるかを決定します。<Link path="/settings/edit#inventory">設定ページの「在庫」タブ</Link>にある「在庫管理方法」項目から、在庫管理方法を選択できます。

デフォルトでは先入先出（FEFO）が使用されますが、複数の管理方法がサポートされています。

## 先入先出（FEFO: First Expired, First Out）

入荷時期に関係なく、有効期限または消費期限が最も早い品目が優先的に販売または使用されます。

最適な用途：生鮮食品、医薬品、食品、および賞味・消費期限が主なリスクとなる厳格な有効期限制限のあるすべての在庫。

### 例

- バッチ番号A: 入荷日 2026-01-10, 有効期限 2026-12-15
- バッチ番号B: 入荷日 2026-02-05, 有効期限 2028-05-20
- バッチ番号C: 入荷日 2026-03-01, 有効期限 2027-07-10

FEFOでは、有効期限が最も早いバッチ番号B（有効期限 2028-05-20）が最初に選択されます。

## 先入先出（FIFO: First In, First Out）

最も古い在庫（最も早く入荷したもの）が最初に販売または使用されます。これは、先に入荷した品目が新しい在庫よりも先に出荷されるべきであるという前提に基づいています。

最適な用途：非生鮮品、陳腐化のリスクが緩やかな商品、および時系列フローを維持することで追跡を簡素化し、長期滞留在庫の発生を抑える運用。

### 例

- バッチ番号A: 入荷日 2026-01-10, 有効期限 2026-06-15
- バッチ番号B: 入荷日 2026-02-05, 有効期限 2028-05-20
- バッチ番号C: 入荷日 2026-03-01, 有効期限 2027-07-10

FIFOでは、入荷日が最も早いバッチ番号A（入荷日 2026-01-10）が最初に選択されます。

## カスタム

カスタムの在庫管理方法では、独自のビジネスルールに基づいて在庫バッチを注文にどのように割り当てるかを決定します。
FIFOとFEFOの組み合わせや、まったく異なるロジックを使用することも可能です。

カスタム方法のご利用については、[サポートにお問い合わせ](https://screenstaring.com/#contact)ください。
