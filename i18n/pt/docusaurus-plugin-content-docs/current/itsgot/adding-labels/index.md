# Adicionando Rótulos ao Seu Site

Existem várias maneiras de adicionar rótulos nutricionais ao seu site.

## Shopify

Se você usa o Shopify, instale nosso [aplicativo Nutrition Facts para Shopify](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

A maioria dos usuários do Shopify deve usar o editor de temas do Shopify para adicionar os rótulos nutricionais.

- [Editor de Temas do Shopify](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Diretamente do Aplicativo para a Descrição de um Produto](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Código de Incorporação

O código de incorporação pode ser usado para fazer o rótulo de um produto aparecer em qualquer lugar.

- [Usando o Código de Incorporação](/docs/itsgot/adding-labels/embed-code)
Você também pode usar a [API Combine](/docs/itsgot/combine-api).
