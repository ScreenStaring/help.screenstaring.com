# Ordem dos Nutrientes

Os nutrientes podem ser listados em qualquer ordem em vez da ordem padrão do formato do rótulo:

1. Encontre o produto desejado e clique no botão "Editar"
1. No editor do rótulo, vá para a seção "Nutrientes"
1. Marque "Usar ordem personalizada"
1. Arraste a alça (⋮⋮) de uma linha para movê-la para cima ou para baixo
   {/* Imagem temporariamente desativada: /itsgot/images/label-custom-nutrient-order.jpg não disponível
   <div>
     <img src="/itsgot/images/label-custom-nutrient-order.jpg" width="700" alt="Personalizando a ordem dos nutrientes de um rótulo" />
   </div>
   */}
1. Clique em <kbd>Atualizar</kbd>

A ordem é usada apenas pelo rótulo. Ela não altera a ordem em que os nutrientes aparecem em qualquer outro lugar.

:::info
A ordem personalizada não está disponível para o formato de rótulo "Tabular".
:::
