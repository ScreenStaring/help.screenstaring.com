# Modificar o Design de um Rótulo

As configurações são aplicadas em 2 níveis:

1. Padrões do site que se aplicam a todos os novos rótulos
2. Valores específicos do rótulo

Os padrões do site podem ser configurados na <Link path="/settings/edit#label-display-settings">página de configurações da sua conta</Link>.

Os valores específicos do rótulo podem ser definidos ao criar ou editar um rótulo na seção <Link path="/nutrition_facts/new#label-display-settings">Configurações de exibição do rótulo</Link>.

Essas configurações são divididas em:

1. **Geral** - Configurações básicas que se aplicam a tudo no rótulo. Largura, tamanho da fonte, etc.
2. **Painel de informações nutricionais** - Configurações que se aplicam especificamente ao painel. Tamanho da borda, cor, espessura, etc.
3. **CSS personalizado** - CSS específico do site para incluir em todos os novos rótulos

As cores e o design dos campos de texto, como ingredientes e avisos, podem ser modificados no próprio campo.

As configurações também podem ser configuradas por linha no painel de informações nutricionais. Isso inclui alterações como recuo, negrito e
adição de links para outros produtos ou páginas do seu site. Para configurar uma linha, clique no link *Configurações de exibição* após selecionar ou inserir um valor:
