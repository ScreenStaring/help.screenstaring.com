# Nutrientes, Ingredientes e Outros Textos

As configurações de exibição não se limitam ao painel como um todo. Nutrientes, ingredientes e outros textos podem ser configurados individualmente:

- **Nutrientes** - cada linha do painel tem um link *Configurações de exibição* onde é possível definir seu recuo, fonte, cor e outros estilos
- **Ingredientes e outros textos** - campos de texto, avisos e blocos de texto são formatados no próprio campo, usando seu menu Formatar

As opções nas páginas a seguir se aplicam a essas áreas:

- [Unidade de Quantidade e Porcentagem](quantity-unit-and-percentage.md)
- [Folato, Ácido Fólico](folate-folic-acid.md)
- [Aminoácidos](amino-acids.md)
