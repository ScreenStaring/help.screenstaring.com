# Vinculando Páginas da Web a Nutrientes do Rótulo


Se sua assinatura incluir <Link path="/app/plans">os recursos do plano Premium</Link>, você poderá transformar um nutriente
ou ingrediente dietético presente no rótulo em um link para uma página da web de sua escolha.

Para criar um link:

1. <Link path="/nutrition_facts/new">Crie</Link> ou edite um rótulo de produto existente
2. Nas seções de <Link path="/nutrition_facts/new#nutrients">Nutrientes</Link> ou <Link path="/nutrition_facts/new?label_format=supplement_vertical#dietary-ingredients">Ingredientes Dietéticos</Link>, adicione ou edite um valor
3. Assim que um valor for inserido, você verá um link *Configurações de exibição*:

   <img src="/help/product-labels-new-display-settings-link.png" width="500" alt="Link Configurações de exibição" />

4. Clique no link para abrir a caixa de diálogo *Configurações de Exibição*. No campo URL da seção *Link*, insira a página para a qual você deseja criar o link.
5. Por padrão, o link será aberto na mesma página. Você pode configurá-lo para abrir em uma nova janela ou guia selecionando *Abrir em nova janela/guia*.
6. Clique em <kbd>Salvar</kbd> ou <kbd>Atualizar</kbd> para salvar
7. Agora, quando o rótulo for exibido em seu site, aparecerá um link do nutriente ou ingrediente dietético para a URL especificada

   <img src="/help/product-labels-nutrient-linked.png" width="500" alt="Nutriente vinculado no rótulo" />

Para alterar a cor do link, consulte a seção [Alterando as Cores e o Design de um Rótulo](/docs/itsgot/display-settings).
