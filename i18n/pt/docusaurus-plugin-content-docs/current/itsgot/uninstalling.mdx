# Desinstalando o Aplicativo


Antes de desinstalar o aplicativo, os rótulos de produtos existentes devem ser removidos.
Isso inclui:

1. Rótulos adicionados automaticamente às descrições dos seus produtos
2. Rótulos adicionados manualmente via código de incorporação

## Rótulos Adicionados Automaticamente às Descrições dos Seus Produtos

Esses rótulos podem ser removidos excluindo todos os seus rótulos. Para fazer isso:

1. Visite a página <Link path="/nutrition_facts">Meus Rótulos</Link>
2. Para cada rótulo que foi adicionado automaticamente, clique no seu botão *Excluir*:

   <img src="/shopify/images/nf-index-delete-product.jpg" alt="Excluir rótulo do produto" />

Se precisar de ajuda, <SupportEmail subject="Remove Product Labels">contate nossa equipe de suporte</SupportEmail>.

## Rótulos Adicionados Manualmente Via Código de Incorporação

O código de incorporação que você adicionou manualmente ao seu site não será removido automaticamente. Você deve fazer isso você mesmo.
Se precisar de ajuda, <SupportEmail subject="Remove Product Labels">contate nossa equipe de suporte</SupportEmail>.
