# Importando Produtos em Massa


Para importar seus produtos em massa:

1. [Baixe nosso modelo de CSV](/itsgot/images/product-import-template.csv)
2. Adicione os dados do seu produto e de nutrição
3. Vá para a página <Link path="/products/import/new">Importação de Produtos</Link> e envie seu arquivo CSV
4. Observe que a planilha de exemplo não contém todos os nutrientes possíveis, veja [Adicionando Nutrientes à Planilha](#adding-nutrients-to-the-spreadsheet)

O modelo de CSV exige valores para as seguintes colunas:

- **Formato do Rótulo**
  Deve ser um dos seguintes:

  - `ca:legacy:nutrition_facts:vertical`
  - `de:eu:nutrition_facts:vertical`
  - `dk:eu:nutrition_facts:vertical`
  - `se:eu:nutrition_facts:vertical`
  - `uk:eu:nutrition_facts:vertical`
  - `us:2016:nutrition_facts:tabular`
  - `us:2016:nutrition_facts:vertical`
  - `us:2016:nutrition_facts:emblems`
  - `us:legacy:nutrition_facts:vertical`
  - `us:legacy:supplement_facts:vertical_columns`
  - `us:legacy:supplement_facts:vertical`
  - `us:2016:supplement_facts:vertical_columns`
  - `us:2016:supplement_facts:vertical`

- **Uma coluna identificadora do produto**
  Deve ser um dos seguintes: ID do Produto/ID da Variante ou SKU. Estes serão usados para associar o produto a um produto correspondente na Shopify.

## Adicionando Nutrientes à Planilha {/* #adding-nutrients-to-the-spreadsheet */}

Qualquer nutriente pode ser importado. Por exemplo, para importar Ômega 3 com uma quantidade de 1000mg você adicionaria uma coluna *Ômega 3* com o valor *1000mg* na linha do produto correspondente.
Se você quisesse especificar um valor de porcentagem, adicionaria uma coluna *Ômega 3 %*:

## Dados Nutricionais com Múltiplas Porções

Use uma coluna *Comments* para separar conjuntos de dados nutricionais do mesmo produto.
