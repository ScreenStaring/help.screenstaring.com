# Porcentagem do tamanho do elemento HTML pai

Uma largura percentual torna o rótulo relativo ao elemento no qual está incorporado, por exemplo, um bloco do tema ou uma coluna da
página do produto. A largura muda quando o tamanho desse elemento muda.

Para fazer um rótulo tão largo quanto o elemento no qual está inserido:

1. Encontre o produto desejado e clique no botão "Editar"
1. Vá para a seção Configurações de exibição do rótulo
1. Selecione "Geral"
1. Preencha o campo "Largura" com a porcentagem desejada. Na maioria dos casos você informará `100` para que o rótulo ocupe toda a largura do elemento pai
1. Selecione `%` no menu de unidades:
   <div>
       <img src="/itsgot/images/label-width-unit-percentage-field.jpg" alt="Selecionando a unidade em porcentagem da largura de um rótulo" />
   </div>
1. Clique em <kbd>Atualizar</kbd>

Um rótulo com largura percentual ainda é limitado pelo espaço que lhe é dado. Por exemplo, um rótulo com largura de `100%` dentro de
uma coluna de 300 pixels de largura também terá 300 pixels de largura.
