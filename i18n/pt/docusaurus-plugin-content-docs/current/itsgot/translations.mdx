# Traduzindo o Texto dos Rótulos


O texto do rótulo pode ser alterado criando-se uma <Link path="/app/translations">tradução</Link>.
As traduções podem ser utilizadas para modificar todo o texto presente no rótulo;
seu uso não se limita estritamente à tradução entre idiomas diferentes.

O uso de traduções requer a [definição da localidade (*locale*) do rótulo](/docs/itsgot/multi-language#multi-language-label-locale).
Uma vez definida, é possível criar traduções para essa localidade que correspondam ao texto original,
substituindo-o por um texto definido pelo usuário.

A tradução de blocos de texto — como listas de ingredientes e avisos — pode ser realizada na página de edição do rótulo, na seção *Traduções*.
Consulte: [Traduzindo Ingredientes e Outros Blocos de Texto](/docs/itsgot/multi-language#multi-language-label-translations).
