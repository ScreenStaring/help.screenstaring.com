# Notificações, Impressão de Pedidos e Romaneios

Isso permite adicionar datas de validade e números de lote a:

-   [Notificações da Shopify](https://www.shopify.com/admin/settings/notifications) (por padrão não se aplica à confirmação do pedido, pois o e-mail é enviado antes que o lote seja atribuído)
-   [Order Printer](https://apps.shopify.com/order-printer) e [Shopify Order Printer](https://apps.shopify.com/shopify-order-printer)
-   [Order Printer Pro](https://apps.shopify.com/order-printer-pro)
-   [Aplicativo Multi-Label Barcodes](https://apps.shopify.com/multi-label-barcodes)
-   E muito mais!

Para começar, você deve habilitar as observações do pedido <Link path="/settings#orders">na página de configurações</Link>, selecionando "Create an order 'additional details' entry for 3rd-party app integration". Depois de habilitado, gere um trecho de código abaixo para a sua integração.

## Trecho de Código

O trecho de código resultante pode ser adicionado ao template Liquid apropriado para a sua integração, no local onde você quer que os dados de validade sejam exibidos. Este trecho funciona **com** o template existente para exibir os dados de validade. Ele não substitui o template.

Se você não encontrar sua integração na lista e precisar de ajuda, contate o suporte.

```liquid
{% comment %}
  Code for the Product Expiration Dates app to display a product's expiration date and related
  informtion in notifications, order printing, & packing slips.

  If you want to hide the expiration date until it's close to a particular number of days
  set the expires_window_days variable below to the number of desired days instead of blank.
  For example:

    {% assign expires_window_days = 30 %}

  For assistance contact support at help@screenstaring.com
{% endcomment %}

{% assign expires_window_days = blank %}

{% capture key %}Expiration Dates {{ line_item.sku }}{% endcapture %}
{% if attributes[key] != blank %}
    {% assign batches = attributes[key] | split: "|" %}
    {% for batch in batches %}
        {% assign batch_data = batch | split: "," %}
        {% assign expires_date = batch_data[0] %}
        {% assign expires_qty = batch_data[1] %}
        {% assign expires_batch = batch_data[2] %}

        {% assign now = "now" | date: "%s" %}
        {% assign seconds_in_a_day = 86400 %}
        {% assign expires_at = expires_date | date: "%s" | plus: seconds_in_day | minus: 1 %}
        {% assign diff = expires_at | minus: now | divided_by: seconds_in_a_day %}
        {% assign show_date = false %}

        {% if expires_window_days == blank  %}
          {% assign show_date = true %}
        {% elsif diff >= 0 and diff < expires_window_days %}
          {% assign show_date = true %}
        {% endif %}

        {% if show_date %}
          {% comment %}
            The date format can be adjust by changing the '%d/%m/%Y' portion below
            to the desired date format codes. See: https://shopify.dev/api/liquid/filters#date
            To use a tranlated date see: https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files
          {% endcomment %}
          Expires:
          {{ expires_date | date: "%d/%m/%Y" }}

          {% comment %}
            Remove the following if you do not want the quantity and batch name displayed
          {% endcomment %}
          ({{ expires_qty }})
          {% if expires_batch != blank %}
              {{ expires_batch }}
          {% endif %}
        {% endif %}
    {% endfor %}
{% endif %}
```

Talvez você precise alterar a variável `line_item` ou `line` para corresponder ao que é usado no seu código existente.

O formato da data é baseado no [filtro `date` do Liquid](https://shopify.dev/api/liquid/filters#date). Ele pode ser ajustado alterando a parte `"%d/%m/%Y"` para usar os códigos de formato de data desejados. Veja a documentação do filtro `date` para obter uma lista. Para usar uma data traduzida, especifique um formato de data [dos arquivos de idioma do seu tema](https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files). Por exemplo, se o formato `month_day_year` existisse (pode ser que sim), você poderia alterar:

```liquid
{{ expires_date | date: "%d/%m/%Y" }}
```

No trecho acima para:

```liquid
{{ expires_date | date: format: "month_day_year" }}
```

## Detalhes Técnicos

Um atributo será adicionado ao pedido para cada item do pedido. O atributo será nomeado `"Expiration Dates [ID]"`, onde `[ID]` é o: SKU, código de barras ou ID da variante na Shopify do item do pedido. O que é usado depende da configuração da sua loja. Se você usa SKUs, será sempre o SKU. Se você usa apenas código de barras, será o código de barras, etc...

O valor do atributo é uma string separada por vírgulas contendo a data de validade atribuída, a quantidade e o número do lote:

```
2023-04-22,2,BATCH-NUMBER
```

Se houver várias atribuições para um item do pedido, cada atribuição será separada pelo caractere pipe (`|`):

```
2023-04-22,2,BATCH-NUMBER-1|2023-12-25,1,BATCH-NUMBER-2
```
