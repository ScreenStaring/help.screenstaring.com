# Compartilhando Estoque Entre Várias Lojas

Se o seu estoque abastece várias lojas, essas lojas podem ser vinculadas. Vincular lojas permite que um único conjunto de dados de validade seja compartilhado entre várias lojas.

Para vincular lojas, você deve:

-   Instalar o aplicativo em cada loja (após o período de teste, todas as lojas devem ter uma assinatura ativa)
-   Usar os mesmos SKUs de produto em cada loja (o código de barras pode ser usado em vez disso, se preferir)
-   Se usar locais, usar os mesmos nomes de local em cada loja
-   [Contatar o suporte](https://screenstaring.com/#contact) para criar o(s) vínculo(s)
