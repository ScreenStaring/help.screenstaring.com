# Alterando o Formato de Data e Hora

O formato de data exibido no aplicativo é determinado pelo seu idioma (locale). Seu idioma pode ser alterado na <Link path="/settings#general">aba general da página de configurações</Link>. Por padrão usamos o idioma fornecido pela Shopify. Alterar o idioma não afeta as datas de validade dos lotes de estoque. Isso só muda o formato usado para exibi-las.

O formato de data exibido no seu site pode ser configurado ao [adicionar dados de validade ao seu site](/docs/product-expiration-dates/shopify-pages).
