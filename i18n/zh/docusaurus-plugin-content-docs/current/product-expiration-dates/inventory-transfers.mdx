# 库存转移

***库存转移支持仅在<Link path="/charges/recurring/new">高级版与白金版套餐</Link>下提供***

如需启用对 [Shopify 库存转移](https://help.shopify.com/zh-CN/manual/products/inventory/inventory-transfers) 的支持：

-   前往<Link path="/settings#inventory">设置页面的“库存”选项卡</Link>
-   勾选“当发生 Shopify 库存转移时移动库存批次”
-   点击“更新”

启用后，每当在 Shopify 中发生库存转移时，转移数量所对应的库存批次将自动从调拨源地点移动到目的地点。批次数量将优先从最早到期的库存批次开始依次扣减转移。如果您需要采用不同的转移算法规则，请联系支持团队。
