# 更改日期和时间格式

应用内显示的日期格式取决于您的语言区域设置。您可以在<Link path="/settings#general">设置页面的“常规”选项卡</Link>中更改语言区域。默认情况下，应用会使用 Shopify 提供的语言区域。更改语言区域不会影响库存批次的到期日数据，仅改变其在界面上的展示格式。

如需配置在您的网店前台展示的日期格式，请参阅[在网店中添加到期数据](/docs/product-expiration-dates/shopify-pages)。
