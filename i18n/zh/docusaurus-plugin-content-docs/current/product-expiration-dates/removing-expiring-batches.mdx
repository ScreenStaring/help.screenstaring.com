# 自动移除即将到期的库存批次

根据到期日自动移除库存批次，可以通过在<Link path="/settings#inventory">设置页面的“库存”选项卡</Link>中勾选“从 Shopify 中移除即将到期的库存”，或者在[规则集](/docs/product-expiration-dates/discounts#rulesets)中添加“移除库存批次”操作来实现。
