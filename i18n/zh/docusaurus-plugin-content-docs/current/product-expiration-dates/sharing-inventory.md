# 在多个店铺之间共享库存

如果您的库存同时供应多个店铺，可以将这些店铺进行关联。关联店铺后，多个店铺即可共享同一套到期数据。

关联店铺的前提条件如下：

-   在每个店铺中均安装该应用（试用期结束后，所有店铺均须具有有效订阅）
-   在每个店铺中使用相同的商品 SKU（如果您愿意，也可以改用条码）
-   如果使用了多地点管理，各店铺中的地点名称必须保持一致
-   [联系支持团队](https://screenstaring.com/#contact)以建立店铺关联
