# 通知、订单打印与装箱单

通过此功能，您可以将到期日和批次号添加到：

-   [Shopify 通知](https://www.shopify.com/admin/settings/notifications)（默认不适用于订单确认邮件，因为该邮件在系统分配批次之前即已发出）
-   [Order Printer](https://apps.shopify.com/order-printer) 和 [Shopify Order Printer](https://apps.shopify.com/shopify-order-printer)
-   [Order Printer Pro](https://apps.shopify.com/order-printer-pro)
-   [Multi-Label Barcodes App](https://apps.shopify.com/multi-label-barcodes)
-   以及更多应用！

开始之前，您必须先在<Link path="/settings#orders">设置页面</Link>中勾选“为第三方应用集成创建订单‘其他详细信息’条目”以启用订单属性功能。启用后，可在下方根据您使用的集成生成相应的代码片段。

## 代码片段

将生成的代码片段添加到您所用集成的相应 Liquid 模版中，放置在您希望展示到期数据的位置。该代码片段旨在与现有模版**协同工作**以显示到期数据，并非用于替换原有模版。

如果您在列表中未找到您所使用的集成且需要协助，请联系支持团队。

### 如果未列出您所使用的集成

```liquid
{% comment %}
  Product Expiration Dates 应用代码：用于在通知、订单打印及装箱单中
  展示产品的到期日及相关信息。

  如果您希望在距离到期日临近指定天数前隐藏到期日，
  可将下方的 expires_window_days 变量修改为所需的天数（而非留空）。
  例如：

    {% assign expires_window_days = 30 %}

  如需协助，请联系支持团队：help@screenstaring.com
{% endcomment %}

{% assign expires_window_days = blank %}

{% capture key %}Expiration Dates {{ line_item.sku }}{% endcapture %}
{% if attributes[key] != blank %}
    {% assign batches = attributes[key] | split: "|" %}
    {% for batch in batches %}
        {% assign batch_data = batch | split: "," %}
        {% assign expires_date = batch_data[0] %}
        {% assign expires_qty = batch_data[1] %}
        {% assign expires_batch = batch_data[2] %}

        {% assign now = "now" | date: "%s" %}
        {% assign seconds_in_a_day = 86400 %}
        {% assign expires_at = expires_date | date: "%s" | plus: seconds_in_day | minus: 1 %}
        {% assign diff = expires_at | minus: now | divided_by: seconds_in_a_day %}
        {% assign show_date = false %}

        {% if expires_window_days == blank  %}
          {% assign show_date = true %}
        {% elsif diff >= 0 and diff < expires_window_days %}
          {% assign show_date = true %}
        {% endif %}

        {% if show_date %}
          {% comment %}
            可通过将下方的 '%d/%m/%Y' 部分修改为所需的日期格式代码来调整日期格式。
            请参阅：https://shopify.dev/api/liquid/filters#date
            如需使用翻译后的本地化日期，请参阅：
            https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files
          {% endcomment %}
          到期日:
          {{ expires_date | date: "%d/%m/%Y" }}

          {% comment %}
            如果您不希望显示数量和批次名称，请删除以下内容
          {% endcomment %}
          ({{ expires_qty }})
          {% if expires_batch != blank %}
              {{ expires_batch }}
          {% endif %}
        {% endif %}
    {% endfor %}
{% endif %}
```

您可能需要将 `line_item` 或 `line` 变量调整为与您现有代码中一致的变量名。

日期格式基于 [Liquid `date` 过滤器](https://shopify.dev/api/liquid/filters#date)。您可以通过修改 `"%d/%m/%Y"` 部分来使用所需的格式代码。格式代码清单请参阅 `date` 过滤器官方文档。如需使用翻译后的日期，可指定[模版语言区域文件中的日期格式](https://shopify.dev/docs/storefronts/themes/architecture/locales/storefront-locale-files)。例如，如果存在名为 `month_day_year` 的格式，您可以将代码片段中的：

```liquid
{{ expires_date | date: "%d/%m/%Y" }}
```

替换修改为：

```liquid
{{ expires_date | date: format: "month_day_year" }}
```

## 技术细节

系统将为订单中的每个明细项添加一个订单属性。属性命名规则为 `"Expiration Dates [ID]"`，其中 `[ID]` 取决于您店铺的设置，可能是该明细项的 SKU、条码或 Shopify 多属性 ID。如果您的店铺使用了 SKU，则始终为 SKU；如果仅使用条码，则为条码等。

属性的值是一个由逗号分隔的字符串，包含分配的到期日、数量和批次号：

```
2023-04-22,2,BATCH-NUMBER
```

如果单个明细项分配了多个批次，各批次记录将通过竖线字符（`|`）进行分隔：

```
2023-04-22,2,BATCH-NUMBER-1|2023-12-25,1,BATCH-NUMBER-2
```
