# Adicionando Rótulos ao Seu Site

Existem várias maneiras de adicionar rótulos nutricionais ao seu site.

## Shopify

Se você usa a Shopify, instale nosso [aplicativo Nutrition Facts para Shopify](https://apps.shopify.com/nutrition-facts?utm_source=screenstaring-documention&utm_medium=web&utm_campaign=app-link).

A maioria dos usuários da Shopify deve usar o editor de temas da Shopify para adicionar os rótulos nutricionais.

- [Editor de Temas da Shopify](/docs/itsgot/adding-labels/shopify/theme-editor)
- [Botão Adicionar à descrição do produto](/docs/itsgot/adding-labels/shopify/directly-from-app)

## Código de Incorporação do Rótulo

O código de incorporação pode ser usado para fazer o rótulo de um produto aparecer em qualquer lugar.

- [Código de Incorporação do Rótulo](/docs/itsgot/adding-labels/embed-code)
Você também pode usar a [API Combine](/docs/itsgot/combine-api).
