# Modificar o Design de um Rótulo

As configurações são aplicadas em 2 níveis:

1. Padrões do site aplicáveis a todos os novos rótulos
2. Valores específicos do rótulo

Os padrões do site podem ser configurados na <Link path="/settings/edit#label-display-settings">página de configurações da sua conta</Link>.

Valores específicos do rótulo podem ser definidos ao criar ou editar um rótulo na seção <Link path="/nutrition_facts/new#label-display-settings">Configurações de Exibição do Rótulo</Link>.
Essas configurações são divididas em:

1. **Geral** - Configurações básicas que se aplicam a tudo no rótulo. Largura, tamanho da fonte, etc.
2. **Painel de Informações Nutricionais** - Configurações que se aplicam especificamente ao painel. Tamanho da borda, cor, espessura, etc.
3. **CSS Personalizado** - CSS específico do site para incluir em todos os novos rótulos

As cores e o design de campos de texto como ingredientes e avisos podem ser modificados dentro do próprio campo.

As configurações também podem ser feitas por linha no painel de informações nutricionais. Isso inclui coisas como alterar o recuo de um nutriente, aplicar negrito ao texto
e adicionar links para outros produtos ou páginas do seu site. Para definir uma configuração para uma linha, clique no link *Configurações de exibição* após
selecionar ou inserir um valor:
