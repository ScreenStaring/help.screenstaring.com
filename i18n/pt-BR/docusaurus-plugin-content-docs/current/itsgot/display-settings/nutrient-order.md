# Ordem dos Nutrientes

Os nutrientes podem ser listados em qualquer ordem em vez da ordem padrão do formato de rótulo:

1. Encontre o produto desejado e clique no botão "Editar"
1. No editor de rótulos, acesse a seção "Nutrientes"
1. Marque a opção "Usar ordem personalizada"
1. Arraste a alça (⋮⋮) em uma linha para movê-la para cima ou para baixo
   {/* Image temporarily disabled: /itsgot/shopify/images/label-custom-nutrient-order.jpg not available
   <div>
     <img src="/itsgot/shopify/images/label-custom-nutrient-order.jpg" width="700" alt="Personalizando a ordem dos nutrientes do rótulo" />
   </div>
   */}
1. Clique em <kbd>Atualizar</kbd>

A ordem é usada apenas pelo rótulo. Ela não altera a ordem em que os nutrientes aparecem em nenhum outro lugar.

:::info
A ordem personalizada não está disponível para o formato de rótulo "Tabular".
:::
