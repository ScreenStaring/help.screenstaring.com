# Traduzindo o Texto dos Rótulos


O texto do rótulo pode ser alterado criando uma <Link path="/app/translations">tradução</Link>.
As traduções podem ser usadas para alterar todo o texto do rótulo, não apenas para traduzir entre idiomas.

O uso de Traduções exige a [definição do locale do rótulo](/docs/itsgot/multi-language#multi-language-label-locale).
Uma vez definido, podem ser criadas traduções para esse locale que correspondam ao texto de origem, substituindo-o pelo texto personalizado do usuário.

A tradução de textos de bloco, como ingredientes e avisos, pode ser feita na página de edição do rótulo, na seção *Traduções*.
Consulte [Traduzindo Ingredientes e Outros Textos de Bloco](/docs/itsgot/multi-language#multi-language-label-translations).
