Usando Dados Estruturados para Melhorar o SEO

Se sua assinatura incluir os recursos do plano Premium, cada produto terá informações nutricionais do Schema.org adicionadas como metafields de variante. Se o produto não tiver variantes, será adicionado como um metafield na variante padrão. Isso permite adicionar dados nutricionais estruturados ao seu site exibindo o(s) metafield(s) apropriado(s) no seu tema.

O exemplo a seguir exibe os dados nutricionais de cada variante como dados estruturados JSON-LD. Isso funciona mesmo se o produto não tiver variantes:

{% for variant in product.variants %}
  {% if variant.metafields.itsgot.schema-org %}
    <script type="application/ld+json">
     {{ variant.metafields.itsgot.schema-org | json }}
    </script>
  {% endif %}
{% endfor %}

Se você precisar adicionar informações adicionais aos dados estruturados antes que sejam exibidos, pode usar o exemplo a seguir como guia. Aqui adicionamos dados de oferta descrevendo o preço de cada variante. O exemplo usa uma combinação de código Liquid e JavaScript. Usamos JavaScript em vez de Liquid puro porque o JavaScript facilita a atualização da estrutura de informações nutricionais:

{% for variant in product.variants %}
  {% if variant.metafields.itsgot.schema-org %}
    <script>
      (function() {
        var schema = {{ variant.metafields.itsgot.schema-org | json }};
        schema.offers = {
          '@type': 'Offer',
          price: {{ variant.price | json }},
          priceCurrency: {{ shop.currency | json }},
          sku: {{ variant.sku | json }},
          availability: "https://schema.org/{% if variant.available %}InStock{% else %}SoldOut{% endif %}",
        };

        var script = document.createElement('script');
        script.setAttribute('type', 'application/ld+json');
        script.textContent = JSON.stringify(schema);
        document.body.appendChild(script);
      })();
    </script>
  {% endif %}
{% endfor %}
